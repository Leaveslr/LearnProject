# Knowledge Video Rubric

Score each category from 0-10, then convert to 100.

## Categories

- Motivation: Does the first 10 seconds make the learner care?
- Mental model: Can a beginner describe the concept in one sentence?
- Concrete walk-through: Is there a small example that moves step by step?
- Formal accuracy: Are formulas, terms, and boundaries correct?
- Completeness: Does it include mechanism, caveat, and summary?
- Visual fit: Does the visual grammar match the concept type?
- Pace: Does each 6-9 second segment carry only one idea?
- Subtitle readability: Can the subtitle be read before it changes?
- Frame quality: Do sampled frames avoid overlap and blank-looking states?
- Reusability: Could the topic be regenerated or modified from structured inputs?

## Minimum Bar

- 85: understandable but may miss boundaries, examples, or polish.
- 90: publishable educational explainer with clear flow and accurate caveats.
- 95: professional course quality with stronger voice, pacing, examples, and visual polish.

## Required Failure Checks

- If terms appear before the learner has a need for them, rewrite the hook.
- If a formula appears without term-by-term translation, add a formula breakdown segment.
- If a system optimization is shown, include what it saves and what it costs.
- If an Agent/workflow is shown, include a concrete trace and a stop condition.
- If a generated frame is only partially visible during an important timestamp, adjust animation timing or evaluate a stable timestamp.
