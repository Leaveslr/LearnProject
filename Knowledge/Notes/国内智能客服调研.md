# 国内智能客服调研

一句话：
国内头部平台的智能客服已经从“问答机器人”升级为“大模型 + Agent + 业务系统调用 + 质检分析闭环”的智能交互系统。

## 调研对象

- 阿里巴巴：AliMe / 通义晓蜜
- 京东：JIMI / 言犀 / 京小智
- 蚂蚁：蚂蚁智能交互系统 / 数字蚂力 / 百灵
- 美团：WOWService

## 总体判断

智能客服的竞争焦点正在发生变化：

- 从“能不能回答”转向“能不能办成事”。
- 从单个机器人转向多 Agent 协同。
- 从售后降本转向服务、导购、成交、质检、运营一体化。
- 从单纯对话能力转向与订单、物流、支付、补偿、预约、营销等业务系统深度打通。
- 从离线训练转向线上坏例发现、自动质检、回归评测和持续迭代闭环。

## 横向对比

| 公司 | 最新核心产品/体系 | 主要方向 | 公开亮点 |
|---|---|---|---|
| 阿里 | 通义晓蜜 | 企业客服 Agent 平台、质检分析 | 全面大模型接入、Agent 化、对话分析、低成本 Turbo 质检 |
| 京东 | 京小智 5.0 / JoyAI | 电商客服 + 导购 + 成交转化 | 多 Agent 矩阵，转人工率降低 28%+，转化率提升 37%+ |
| 蚂蚁 | 数字蚂力 AI 数字客服 + 百灵 | 企业数字员工、可信交互、服务业运营 | 人效提升约 70%，成本降低 35%，多专家 Agent 协同 |
| 美团 | WOWService | 本地生活智能交互系统 | 数据知识双驱动、多 Agent、自我优化，App 已部署 |

## 阿里：AliMe / 通义晓蜜

阿里体系里，AliMe 的公开品牌重心已经更多转向通义晓蜜。2025 云栖大会上，阿里云披露通义晓蜜已完成全面大模型接入和 Agent 化升级，定位为覆盖“营、销、服”的泛客服解决方案。

通义晓蜜的核心方向是把阿里过去在电商客服里的经验产品化，沉淀成云上的企业客服 Agent 平台。它更像一个可配置、可接入、可运营的客服中台，而不是只面向单一场景的聊天机器人。

### 关键能力

- 对话 Agent 构建：支持客服 Agent、业务流程编排、高频问答知识、API 插件、参数收集、敏感安全策略和兜底机制。
- 大模型质检：支持复杂质检、多轮对话理解、深层语义理解和智能路由。
- 对话分析：支持信息抽取、场景分类、满意度判定、投诉预警、销售机会识别等。
- 成本分层：2026 年 1 月升级中新增通义晓蜜-Turbo，并提供 Plus、Turbo、Agent 智能路由三种模式。

### 我的理解

阿里的强项是产品化和生态输出。通义晓蜜不是只解决阿里内部客服，而是把客服、营销、销售、质检、分析做成企业可购买和可集成的云服务。

## 京东：JIMI / 言犀 / 京小智

京东早期智能客服常见品牌包括 JIMI、言犀等，最新公开动作集中在京小智 5.0。2025 年 9 月 JDD 大会发布的京小智 5.0，被定位为电商客服 Agent 原生应用，面向京东中小商家免费开放。

京东的特点是客服和交易链路绑定很深。它不只是降低人工客服压力，还明显承担导购、跟单、销售转化和商家经营分析的任务。

### 关键能力

- 多 Agent 协作：覆盖客服、导购、跟单、分析、质检等环节。
- 业务系统打通：可接入国补、物流、活动、价保等京东平台业务系统。
- 导购能力：通过需求探明、推荐理由、商品推荐、商品答疑等 Agent 协同提升推荐准确性。
- 全量质检：支持秒级实时全量质检，覆盖 30+ 官方预置场景。

### 公开效果

- 5 万家店铺内测中，转人工率降低 28% 以上。
- 用户满意度提升 15% 以上。
- 售前咨询转化率增长 37% 以上。
- 商品推荐准确率提升 40%+。
- 2025 年 618 前后，京小智 5.0 服务商家增长至超 90 万家，大模型导购带动商家咨询转化率提升超 20%。

### 我的理解

京东的核心优势是电商交易数据、商品知识和履约系统。它的智能客服已经明显从“售后工具”演化成“服务即销售”的经营系统。

## 蚂蚁：智能交互系统 / 数字蚂力 / 百灵

公开资料里，“蚂蚁智能交互系统 ANT”不是一个稳定统一的客服产品品牌。能对应到智能客服和智能交互的最新公开进展，主要集中在数字蚂力 AI 数字客服、蚂蚁百灵大模型，以及面向多模态交互的灵光应用。

蚂蚁的路线更偏“企业数字员工 + 可信交互”。相比单纯客服问答，它更强调多个专家智能体协同完成服务、营销、知识运营、质检评测等任务。

### 关键能力

- AI 数字客服团队：由服务设计、知识运营、效果评测等多个专家智能体协同。
- 流程执行：可覆盖咨询、导购、下单、预约等流程。
- 百灵大模型底座：包含 Ling 语言模型、Ring 推理模型、Ming 多模态模型系列。
- 多模态交互探索：灵光支持语言、图像、语音、数据理解与生成，并可输出交互式结果。

### 公开效果

- 数字蚂力公开称可提升约 70% 人效、降低 35% 运营成本。
- 在部分电商客户实践中带来约 10% GMV 增长。
- 乐刻案例中，AI 数字客服解决率超过 85%。

### 我的理解

蚂蚁更适合关注金融、生活服务、企业运营和高合规场景。它的客服路线不是只做对话，而是让 AI 成为一个能协同、能评测、能运营的数字员工团队。

## 美团：WOWService

美团是四家公司里公开技术细节最多的一家。2025 年 11 月，美团 LongCat Interaction 团队发布 WOWService 大模型交互系统技术报告，明确称其来自美团智能客服和多业务场景落地经验。

WOWService 的核心框架包括数据与知识双驱动、自我优化训练、四阶段训练流水线、多 Agent 协同。它主要落地在美团智能客服系统，并覆盖美团内部数十个业务场景。

### 关键能力

- 数据与知识双驱动：同时利用客服真实对话、业务知识、服务规则和知识驱动生成数据。
- 四阶段训练：CPT、SFT、DPO、RL 共同支撑领域适配和服务质量提升。
- 多 Agent 协同：适配外呼、主动协同、多模态理解等复杂服务场景。
- 自我优化：通过在线质检、离线坏例、自动评测和回归测试持续迭代。
- 风险控制：2025 年 9 月披露逆向学习 / Unlearning 技术，用于精准抑制特定错误和风险行为。

### 公开效果

- 仅需 10% 的小模型标注数据即可达到传统方案相当效果。
- 在 11 项关键指标上超越 Base 模型。
- arXiv 技术报告披露，WOWService 已部署在美团 App。
- 用户满意相关指标有明显改善，例如 USM 1 下降 27.53%、USM 2 提升 25.51%。
- 逆向学习相关风险控制指标提升 38 个百分点以上，同时保持整体服务效果不下降。

### 我的理解

美团路线最工程研究型。它解决的是本地生活里的复杂履约问题：订单、配送、用户、商家、规则、权益和补偿交织在一起，客服系统必须能理解业务状态、调用工具、遵守规则，并通过评测闭环稳定演进。

## 共同技术趋势

### 1. Agent 原生化

各家都在把客服系统从单机器人改造成 Agent 系统。常见 Agent 包括客服 Agent、导购 Agent、质检 Agent、分析 Agent、知识运营 Agent、流程执行 Agent。

### 2. 业务工具调用成为核心

客服价值不再只是“生成一句回答”，而是能查询订单、判断规则、调用补偿、修改预约、推荐商品、创建工单和推进流程。工具调用能力决定客服系统能否从“解释问题”升级为“解决问题”。

### 3. 质检分析成为闭环入口

大模型客服必须通过质检和分析不断发现坏例。阿里重对话分析和质检产品化，京东重商家全量质检，美团重坏例回流和回归评测，蚂蚁重专家 Agent 协同评测。

### 4. 服务增长一体化

京东的导购转化、美团的服务满意度、蚂蚁的 GMV 增长案例、阿里的营销售服一体化都说明：客服已经从成本中心变成经营入口。

### 5. 垂直业务系统是护城河

大模型能力本身会逐渐普及，但订单、履约、支付、物流、商家规则、用户权益、历史会话和质检数据是平台型公司的优势。真正难的是把模型放进复杂业务系统里稳定运行。

## 可继续研究的问题

- 各家公司在人工客服与 AI 客服之间如何分工和交接？
- 大模型客服的安全边界如何设计，尤其是退款、补偿、金融、合规类场景？
- Agent 之间的任务拆分、冲突处理和责任归因如何实现？
- 智能客服评测指标如何从“回答正确”升级到“任务完成”和“用户满意”？
- 企业外部采购时，应选择通用客服 SaaS、平台原生工具，还是自建 Agent 中台？
