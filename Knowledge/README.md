# Knowledge Vault

这是一个适合 Obsidian 和 VS Code 同时使用的 Markdown 知识库。

## 使用方式

- 用 Obsidian 打开 `Knowledge/` 文件夹作为 vault。
- 用 VS Code 打开同一个文件夹做批量编辑、搜索和 Git 管理。
- 新内容先放进 `Inbox/`，整理后再移到对应目录。

## 目录

- `Inbox/`：临时收集
- `Notes/`：长期笔记
- `Links/`：链接收藏和摘要
- `Projects/`：项目相关材料
- `MOCs/`：主题索引
- `Daily/`：每日记录
- `Papers/`：下载的论文 PDF、官方 README 和网页快照
- `Templates/`：笔记模板
