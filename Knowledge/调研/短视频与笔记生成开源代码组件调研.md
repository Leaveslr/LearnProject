# 短视频与笔记生成开源代码组件调研

一句话：当前开源生态已经能覆盖“知识文本 -> 小红书图文卡片 -> 短视频脚本/配音/字幕/竖屏视频”的主要链路，但适合直接接入的不是一个大而全项目，而是“内容结构化 + 图文卡片渲染 + 视频模板渲染 + 字幕/裁切组件”的组合。

## 结论先行

建议把后续生产系统拆成两条主线：

1. 小红书图文笔记：优先参考 RedInk 和 Xiaohongshu Content Generator 的卡片生成思路，把知识包拆成封面、标题、分镜页、结尾页，再用 HTML/CSS 或前端组件批量渲染图片。
2. 短视频：优先参考 Short Video Maker 的“文本 -> TTS -> 字幕 -> 背景视频 -> Remotion 合成”流水线；长视频切片场景再参考 OpenShorts、AI YouTube Shorts Generator、ViralCutter。
3. 发布自动化：小红书发布相关项目只能作为实验和内部工具参考，不应作为核心生产依赖。平台规则、登录态、风控和接口变化会让它成为高维护成本环节。

最适合本工作区的路线：

- `knowledge-core` 继续沉淀知识和选题。
- `content-production-studio` 接收知识包，先生成结构化内容稿。
- 图文笔记用本地模板渲染为卡片图。
- 短视频用脚本、TTS、字幕和 Remotion/FFmpeg 渲染。
- 发布阶段保留人工确认，自动化只做素材准备和草稿辅助。

## 项目横向对比

| 类别 | 项目 | 核心能力 | 技术栈/组件 | 适配判断 |
|---|---|---|---|---|
| 短视频平台型 | [OpenShorts](https://github.com/mutonby/openshorts) | 自托管 AI video platform，包含 Clip Generator、AI Shorts、YouTube Studio，支持从长视频或本地文件生成竖屏内容 | Docker、Web 平台、AI 分析、字幕、竖屏剪辑 | 适合作为架构参考或本地试用；系统较大，不宜直接嵌进内容仓库 |
| 文本转短视频 | [Short Video Maker](https://github.com/gyoridavid/short-video-maker) | 从文本输入生成短视频，包含 TTS、自动字幕、背景视频、音乐，并支持 REST API 和 MCP | Kokoro TTS、Whisper、Pexels、Remotion、FFmpeg | 最适合参考流水线设计；可拆成独立视频生成服务 |
| 长视频切片 | [AI YouTube Shorts Generator](https://github.com/samuraigpt/ai-youtube-shorts-generator) | 用 LLM 做高光识别，用 Whisper 转录，并自动裁切为 TikTok/Reels/Shorts 竖屏片段 | Python、LLM、Whisper、OpenCV/FFmpeg | 适合播客、访谈、课程长视频二创；不适合作为知识包首发内容主链路 |
| 本地剪辑替代 | [ViralCutter](https://github.com/RafaelGodoyEbert/ViralCutter) | 本地生成面向 TikTok/Instagram 的短视频剪辑，含转录、9:16 编辑、动态字幕等 | WhisperX、本地剪辑、字幕样式、竖屏处理 | 适合研究剪辑体验和字幕表现；成熟度需单独验证 |
| 小红书图文生成 | [RedInk](https://github.com/HisMax/RedInk) | 一句话生成小红书图文，覆盖大纲、封面、多页内容图等 | Vue、Flask、Docker、Gemini/Nano Banana Pro | 最适合参考小红书图文产品形态和批量卡片生成流程 |
| 小红书生成发布 | [YYH211/xiaohongshu](https://github.com/YYH211/xiaohongshu) | 从主题输入到内容生成和发布，通过 MCP 集成多种工具服务 | Web 应用、MCP、自动发布 | 可研究端到端自动化，但发布能力不宜作为稳定依赖 |
| 博客转卡片 | [Xiaohongshu Content Generator](https://github.com/shaozheng0503/Xiaohongshu-Content-Generator) | 将博客文章转成小红书风格图片与文案，支持模板、主题、批量和 API 自动化 | Flask、本地渲染、多模板、多语言 | 很适合参考“长文/知识稿 -> 图文卡片”的转换逻辑 |
| 通用社媒文案 | [SocialToolkit](https://github.com/tvcnet/social-toolkit) | 使用自选 AI Provider 生成社媒内容，无登录、无订阅、强调本地隐私 | JavaScript、TailwindCSS、Alpine.js、OpenAI/Claude/Ollama/Gemini | 适合参考多平台文案参数化，不适合作为小红书视觉生产核心 |

## 组件能力地图

| 能力 | 推荐组件/项目 | 适合承担的职责 | 注意点 |
|---|---|---|---|
| 内容结构化 | 自研模板、LLM、SocialToolkit 思路 | 将知识包拆成标题、钩子、正文页、行动页、视频分镜 | 需要保留来源和事实边界，避免纯营销化改写 |
| 图文卡片渲染 | RedInk、Xiaohongshu Content Generator、HTML/CSS 截图 | 批量生成封面图、内容页、长图、PDF 或 PNG | 中文排版、换行、字号、封面信息密度要单独做质量门 |
| 视频模板渲染 | [Remotion](https://www.remotion.dev/)、Short Video Maker | 用 React/CSS/Canvas/SVG/WebGL 生成 MP4，适合模板化、批量化视频 | 对前端模板工程要求较高，但很适合知识类视频的可复用版式 |
| 媒体处理 | [FFmpeg](https://ffmpeg.org/about.html)、[MoviePy](https://zulko.github.io/moviepy/) | 转码、裁切、拼接、抽帧、音频处理、字幕烧录 | FFmpeg 稳定但命令复杂；MoviePy 更易写 Python 自动化 |
| 字幕/转录 | Whisper、[faster-whisper](https://github.com/SYSTRAN/faster-whisper)、WhisperX | 从音频生成字幕，支持词级时间戳和字幕对齐 | 中文标点、断句和专有名词需要二次校正 |
| 配音 | Kokoro TTS、Edge TTS、ElevenLabs | 文本转语音，生成旁白音轨 | 中文自然度、商用授权、声音一致性要逐项确认 |
| 竖屏裁切 | OpenShorts、AI YouTube Shorts Generator、ViralCutter、OpenCV、MediaPipe、YOLO | 将横屏长视频裁为 9:16，做人脸/主体跟踪 | 对知识讲解类视频不是必需；对访谈/播客切片更重要 |
| 发布/分发 | YYH211/xiaohongshu、其他 XHS MCP 工具 | 搜索、发布、登录态管理、草稿辅助 | 平台规则变化快，建议只用于低频辅助和内部实验 |

## 适配本工作区的建议

### 可以直接进入 `content-production-studio` 的方向

- 结构化笔记生成器：输入 `knowledge-pack`，输出小红书笔记 JSON，包括标题、封面文案、正文页、标签、首评、风险提示。
- 卡片渲染器：用 HTML/CSS 或前端组件把 JSON 渲染为固定比例图片，优先支持 3:4、4:5、3:5 和 1:1。
- 短视频脚本生成器：输入知识包和图文稿，输出 30 秒、60 秒、90 秒三个版本的口播脚本和分镜。
- 视频模板渲染器：用 Remotion 或 FFmpeg 组合标题页、字幕、背景、B-roll、音频和结尾 CTA。

### 适合作为架构参考的方向

- OpenShorts：参考它把 Clip Generator、AI Shorts、YouTube Studio 放在同一平台内的模块边界。
- Short Video Maker：参考它把 TTS、字幕、素材检索、Remotion 合成串成服务接口的方式。
- RedInk：参考它的“主题 -> 大纲 -> 封面 -> 多页图文”的图文生产体验。
- Xiaohongshu Content Generator：参考它的“长文 -> 卡片”的模板化批处理。

### 暂不建议直接集成的方向

- 自动发布小红书：可调研、可低频试用，但不要作为核心链路强依赖。
- 完整替换为大而全平台：OpenShorts 这类项目适合试跑和借鉴，不建议直接塞入当前双仓库结构。
- 纯素材拼接型短视频：如果没有知识结构、讲解节奏和事实校验，只会提高产量，不一定提高内容质量。

## 风险与限制

- 维护活跃度：小红书图文项目很多是个人项目，Star 和热度不等于长期可维护性。
- 中文效果：字幕断句、TTS 自然度、卡片换行、标题密度，都需要中文内容专项测试。
- 模型/API 依赖：RedInk 等项目依赖特定模型或 API Key，后续可用性和成本会变化。
- 素材版权：Pexels、背景视频、音乐、字体、声音模型都要明确授权范围。
- 平台风控：自动登录、自动发布、自动互动容易受平台规则影响，也可能触发账号风险。
- 许可证：OpenShorts、MoviePy、faster-whisper 等有明确开源许可；部分小红书项目需要逐仓库核对 LICENSE 后再集成代码。

## 推荐落地路线

第一阶段：做“图文笔记生成”闭环。

- 输入：`knowledge-core` 导出的知识包。
- 输出：小红书笔记 Markdown/JSON、封面文案、卡片页文案、标签。
- 参考：RedInk、Xiaohongshu Content Generator、SocialToolkit。
- 验收：同一知识包能稳定生成 6-9 页图文结构，卡片文字不溢出，标题和首图能说明主题。

第二阶段：做“模板化短视频”闭环。

- 输入：图文笔记 JSON 或知识包。
- 输出：口播稿、字幕 SRT、配音音频、9:16 MP4。
- 参考：Short Video Maker、Remotion、FFmpeg、faster-whisper。
- 验收：能生成 30-90 秒竖屏视频，字幕同步，中文断句可读，素材来源可追踪。

第三阶段：做“长视频切片”实验。

- 输入：已有课程、访谈、直播或长讲解视频。
- 输出：高光片段、自动字幕、竖屏剪辑候选。
- 参考：OpenShorts、AI YouTube Shorts Generator、ViralCutter。
- 验收：只作为候选素材生产，不自动发布；人工审核通过后进入 campaign。
