# LLM Knowledge Book

> 面向大模型算法岗和 AI Engineer 的渐进式学习笔记。

这个仓库的目标不是简单堆资料，而是把 LLM 相关知识整理成一条可复习、可追问、可扩展的学习主线。建议先读 `src` 中的整理笔记，再按需要回到 `raw` 查看原始资料。

建议按下面 5 轮推进：

1. **基础与语言模型**：先补机器学习、深度学习、Tokenizer、next token prediction。
2. **模型架构基础**：理解 Transformer、Attention、位置编码、GQA/MLA、MoE。
3. **训练与对齐**：学习预训练、SFT、RLHF/DPO/GRPO、PEFT/LoRA。
4. **推理与应用系统**：掌握 KV Cache、FlashAttention、PagedAttention、RAG、Agent。
5. **评估与面试闭环**：用评估体系和真实面试题检查知识点，整理项目表达和内容选题。

## 后续补齐清单

当前仓库已经有一条可学习主线，基础层和推理显存计算已经开始拆成独立专题。后续还缺少一些应继续深化的内容：

- **基础原理深化**：KL 散度、矩阵计算、反向传播、梯度裁剪、batch size 与泛化。
- **训练技术深化**：继续补 DPO、GRPO/GSPO 的独立推导和训练实践。
- **推理优化深化**：继续补 Speculative Decoding、Continuous Batching、Prefix Cache 的独立专题和成本建模练习。
- **RAG 深化**：继续补 Embedding 模型、向量数据库、rerank、GraphRAG 的独立专题。
- **Agent 工程化**：继续补 LangGraph / MCP 实战样例和 Agent eval 数据集设计。
- **项目表达**：项目复盘模板、STAR 表达、算法岗项目追问清单。

## 维护原则

- README 只链接已经存在的笔记文件。
- `src` 写成可学习的知识结构，`raw` 只做资料归档。
- `templates` 用于把知识点转换成个人笔记、小红书图文、视频脚本。
- 每个主线章节建议包含：核心概念、公式/流程、工程实现、常见坑、面试追问。
- 面试题优先按知识点归类，不按公司堆叠。
- 新增章节后同步更新本 README。
