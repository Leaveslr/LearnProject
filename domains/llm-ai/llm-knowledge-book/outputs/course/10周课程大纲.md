# LLM 系统掌握 10 周课程大纲

> 面向目标：从“知道一些大模型名词”升级到“能系统理解 LLM 原理、训练、推理、RAG、Agent、评估和面试表达”。

## 课程定位

这不是资料堆叠课，而是一门主线课：

```text
文本如何变成 token
-> token 如何进入 Transformer
-> 模型如何训练
-> 模型如何对齐和微调
-> 模型如何高效推理
-> 模型如何接入 RAG / Agent 应用
-> 系统如何评估、安全上线和面试表达
```

## 适合人群

- 想系统学习 LLM 的算法岗 / AI Engineer。
- 已经听过 Transformer、RAG、Agent，但知识点不成体系的人。
- 需要准备大模型面试，需要把项目讲清楚的人。
- 想把学习笔记持续转成内容资产的人。

## 课程验收标准

学完后应该能做到：

- 画出 LLM 从 token 到生成文本的完整链路。
- 解释 Transformer block 每个组件的作用。
- 区分预训练、SFT、RLHF、DPO、LoRA 的目标和数据形态。
- 估算 KV Cache 显存，并解释推理服务指标。
- 设计一个 RAG 系统并排查错误。
- 设计一个可控 Agent，并解释工具调用风险。
- 为项目准备 30 秒、2 分钟和深挖版表达。

## 每周学习节奏

每周建议按四步推进：

1. 学主线：读 `src` 中对应章节。
2. 做练习：完成本课程题库中的对应题。
3. 产出卡片：写一张知识卡或面试卡。
4. 复盘表达：用 2 分钟讲给别人听。
