# 短视频脚本：RAG 效果差，到底怪谁？

## 选题

本期讲：RAG 评估的三层排障法。

## 开头 0-5 秒

```text
RAG 答错了，别第一反应就怪模型幻觉。
```

## 第一段 5-25 秒

```text
RAG 像开卷考试。先问资料有没有找对，再问资料有没有放进上下文，最后才问模型有没有按资料回答。
```

画面：检索 -> 上下文 -> 答案。

## 第二段 25-70 秒

```text
检索层看 Recall@k、MRR、nDCG。
上下文层看 context recall、relevance 和冗余率。
答案层看 faithfulness、事实正确性和引用准确性。
```

## 第三段 70-100 秒

```text
线上还要看无答案率、检索空结果率、人工转接率、延迟和成本。
评估集要有 easy、hard、adversarial 和历史失败样本。
```

## 结尾

```text
一句话记住：RAG 评估不是看一个分数，而是定位哪一层坏了。
```
