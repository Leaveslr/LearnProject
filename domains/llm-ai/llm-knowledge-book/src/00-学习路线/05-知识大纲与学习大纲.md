# 知识大纲与学习大纲

> 用于明日讨论学习计划。目标是把知识库拆成可学习、可复习、可输出内容的路线。

## 一、知识大纲

### 0. 学习方法与内容转化

- 学习路线与知识地图。
- 学习笔记到小红书 / 视频脚本的转化流程。
- 学习状态标注。
- 数据源跟踪。

输出物：

- 每日学习记录。
- 每个知识点的 1 张面试卡。
- 每周至少 1 篇小红书或 1 条短视频脚本。

### 1. 基础原理

- 概率、最大似然、交叉熵。
- 梯度下降、Adam、学习率调度。
- Embedding、向量相似度、归一化。
- 激活函数、残差连接、LayerNorm / RMSNorm。
- 采样策略：temperature、top-k、top-p。

核心问题：

- 为什么语言模型用 next token prediction？
- 交叉熵和最大似然是什么关系？
- 为什么 Transformer 大量使用归一化和残差？

### 2. Tokenizer 与语言模型

- 字符、词、subword token。
- BPE、WordPiece、SentencePiece。
- 中文 tokenizer 的特殊问题。
- context length、token budget、压缩表达。
- perplexity 与语言建模评估。

核心问题：

- 为什么 tokenizer 会影响模型效果和成本？
- 为什么中文 token 数常常比英文更敏感？
- tokenizer 改动为什么会影响模型词表和 embedding？

### 3. Transformer 与模型架构

- Transformer block。
- Self-Attention、Cross-Attention、Causal Mask。
- RoPE、ALiBi、长上下文外推。
- MHA、MQA、GQA、MLA。
- FFN、SwiGLU、MoE。
- 主流模型架构对比。
- 多模态模型结构。

核心问题：

- Attention 到底在计算什么？
- GQA 为什么能降低 KV Cache 成本？
- MoE 为什么能扩大参数但不线性增加推理开销？

### 4. 训练与对齐

- 预训练数据、目标函数、训练稳定性。
- SFT 与指令微调。
- PEFT、LoRA、QLoRA。
- RLHF、Reward Model、PPO。
- DPO、GRPO。
- 数据工程、数据配比、benchmark contamination。

核心问题：

- 预训练、SFT、RLHF、DPO 分别解决什么问题？
- LoRA 的低秩假设是什么？
- 为什么偏好数据和高质量指令数据很关键？

### 5. 推理优化与部署

- KV Cache。
- FlashAttention。
- PagedAttention。
- Continuous Batching。
- Prefix Cache。
- Speculative Decoding。
- FP16、BF16、INT8、INT4、NF4。
- 吞吐、延迟、显存、成本建模。

核心问题：

- KV Cache 显存怎么算？
- PagedAttention 解决了什么内存问题？
- 量化为什么会影响不同任务的效果？

### 6. RAG 系统

- 文档解析、清洗、切分。
- Embedding 与向量库。
- 稀疏检索、向量检索、混合检索。
- rerank。
- prompt 拼接与引用溯源。
- GraphRAG、Agentic RAG。
- RAG 评估与排障。

核心问题：

- 如何判断 RAG 错在检索还是生成？
- chunk size 怎么选？
- RAG、微调、长上下文分别适合什么场景？

### 7. Agent 系统

- workflow vs agent。
- ReAct、Plan-and-Execute。
- tool use、function calling、MCP。
- memory、state、HITL。
- 多 Agent 协作。
- Agent observability。
- Agent eval、guardrails、安全边界。

核心问题：

- 什么时候需要 Agent，而不是普通 RAG？
- 工具调用失败如何恢复？
- 多 Agent 为什么可能更差？

### 8. 评估与安全

- LLM eval。
- RAG eval。
- Agent eval。
- LLM-as-judge。
- golden set、人工标注、线上反馈。
- 幻觉、越狱、提示注入、数据泄露。
- 回归测试与持续评估。

核心问题：

- eval 数据集怎么构造？
- 如何避免只看平均分？
- 为什么 Agent 评估必须看 trace？

### 9. 面试与项目表达

- 高频知识点问答。
- 真实面试题归类。
- 项目 STAR 表达。
- 指标、baseline、失败案例。
- 算法题与工程题复盘。

核心问题：

- 如何把项目讲成“问题、方案、指标、复盘”？
- 面试官追问底层原理时如何回到知识主线？
- 不会的问题如何展示思考质量？

### 10. 内容创作

- 知识点选题库。
- 小红书图文结构。
- 短视频脚本结构。
- 标题、封面、类比、反常识点。
- 从面试题反推内容选题。

核心问题：

- 哪些知识点适合做科普？
- 哪些知识点适合做面试向内容？
- 如何避免内容只停留在概念解释？

## 五、默认学习状态

当前默认全部标为 `未开始`。明天讨论后，建议把你已经熟悉的模块改成 `需复盘` 或 `学习中`，不要直接标 `已掌握`。只有能独立回答验收问题、能讲给别人听、能应对 2-3 个追问时，才标为 `已掌握`。
