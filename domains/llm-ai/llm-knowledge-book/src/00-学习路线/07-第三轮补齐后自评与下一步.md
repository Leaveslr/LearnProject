## 本轮后体系变化

### 1. 基础原理从“综述”变成“可学习单元”

之前基础部分主要是一篇总览。现在已经拆出：

- 损失函数。
- Embedding。
- 优化器。
- 归一化、残差、激活函数。

这能解决一个关键问题：学习 Transformer 时，不会遇到交叉熵、Embedding、LayerNorm、AdamW 就只能背概念。

### 2. Transformer 主线更连续

新增依赖图后，学习顺序更清楚：

```text
文本 -> token -> embedding -> position -> attention -> FFN/norm/residual -> logits -> decoding -> KV Cache
```

这比单独读 Attention、位置编码、MoE 更适合建立整体理解。

### 3. 推理优化开始具备计算能力

新增 KV Cache 显存专题后，不再只停留在“KV Cache 能加速”。

现在应该能回答：

- KV Cache 到底存什么。
- 显存公式怎么写。
- batch size、seq len、层数、KV head 数如何影响显存。
- GQA/MQA 为什么能省推理显存。
- PagedAttention 和 Prefix Cache 分别解决什么。
