# 机器学习与深度学习基础

> 目标：补齐学习 LLM 前必须稳定掌握的基础概念，避免只会背大模型术语。

## 一句话结论

LLM 的核心仍然是概率建模、表示学习和梯度优化；Transformer 只是把这些基础能力组织成了适合大规模序列建模的结构。

## 1. 概率建模基础

### 条件概率

语言模型本质是在建模：

$$P(x_1, x_2, ..., x_n) = \prod_{t=1}^{n} P(x_t | x_{<t})$$

也就是给定前文，预测下一个 token。

面试常见追问：

- 为什么自回归模型可以生成文本？
- 训练时 teacher forcing 和推理时逐 token 生成有什么差异？

### 最大似然估计

训练语言模型通常等价于最大化训练数据的似然：

$$\max_\theta \sum_{t=1}^{n} \log P_\theta(x_t | x_{<t})$$

实际实现里通常最小化负对数似然，也就是交叉熵损失。

## 2. 损失函数

### 交叉熵

分类任务中，交叉熵衡量真实分布和预测分布的距离：

$$L = -\sum_i y_i \log \hat{y}_i$$

对 next token prediction 来说，真实标签通常是 one-hot，损失就是目标 token 的负 log probability。

### Perplexity

Perplexity 可以理解为模型对下一个 token 的平均困惑程度：

$$PPL = \exp(\text{CrossEntropy})$$

注意：PPL 适合衡量语言建模能力，但不能充分衡量对话质量、事实性、RAG 可靠性或 Agent 任务成功率。

## 3. 优化器

### SGD

SGD 用小批量样本估计梯度并更新参数：

```text
theta = theta - lr * grad
```

优点是简单，缺点是对学习率敏感、收敛可能慢。

### Adam / AdamW

Adam 同时维护一阶动量和二阶动量：

- 一阶动量：梯度方向的滑动平均。
- 二阶动量：梯度平方的滑动平均。

AdamW 将权重衰减从梯度更新中解耦，是训练 Transformer 时常见选择。

面试要点：

- Adam 为什么比 SGD 更适合大模型训练？
- AdamW 和 Adam + L2 正则有什么区别？
- warmup 和 learning rate decay 为什么重要？

## 4. 归一化

### BatchNorm

BatchNorm 在 batch 维度上统计均值和方差，常用于 CNN。

### LayerNorm

LayerNorm 在单个样本的 hidden dimension 上归一化，更适合变长序列和自回归模型：

$$\text{LN}(x)=\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}\gamma+\beta$$

Transformer 常用 LayerNorm，因为推理时 batch size 可变，序列长度也可变，BatchNorm 的统计量不稳定。

### RMSNorm

RMSNorm 只使用均方根做缩放，省掉均值中心化：

$$\text{RMSNorm}(x)=\frac{x}{\sqrt{\frac{1}{d}\sum_i x_i^2+\epsilon}}\gamma$$

很多现代 LLM 使用 RMSNorm，原因是计算更轻，训练也稳定。

## 5. 激活函数

### ReLU

简单高效，但负半轴梯度为 0，可能出现 dead neuron。

### GELU

Transformer 早期常用 GELU，平滑且更适合深层网络。

### SwiGLU

现代 LLM 常用 SwiGLU 作为 FFN 激活变体，通常形式为：

```text
FFN(x) = W2(SiLU(W1 x) * W3 x)
```

它比普通 ReLU/GELU FFN 表达能力更强，但参数和计算也会变化。

## 6. 表示学习

Embedding 将离散 token 映射为连续向量。语言模型不是直接处理文字，而是处理 token id 对应的向量。

关键点：

- token embedding 表达词或子词的语义。
- position encoding 表达序列位置。
- hidden states 是上下文相关表示。

## 7. 常见误区

- **误区 1：大模型知识和传统 ML/DL 无关。** 实际上损失函数、优化器、归一化、表示学习仍是底层基础。
- **误区 2：PPL 低就一定效果好。** PPL 只能反映语言建模分布拟合，不能替代任务评估。
- **误区 3：LayerNorm 只是防止梯度爆炸。** 它还改善优化条件，使深层网络更稳定。

## 面试追问

### Q1：为什么 Transformer 常用 LayerNorm 而不是 BatchNorm？

回答：Transformer 面向变长序列和自回归推理，batch 统计不稳定；LayerNorm 对每个样本独立归一化，不依赖 batch size，更适合 NLP 和生成任务。

### Q2：交叉熵和最大似然是什么关系？

回答：在 one-hot 标签下，最小化交叉熵等价于最大化目标 token 的对数似然。

### Q3：为什么 AdamW 常用于 LLM 训练？

回答：Adam 适合稀疏和非平稳梯度，AdamW 解耦 weight decay，让正则化更稳定；配合 warmup 和 decay 能提升大规模训练稳定性。
