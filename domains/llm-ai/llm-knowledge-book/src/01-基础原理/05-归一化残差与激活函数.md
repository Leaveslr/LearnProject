# 归一化、残差连接与激活函数

## 一句话结论

归一化让训练更稳定，残差连接让深层网络更容易传递信息，激活函数让模型具备非线性表达能力。三者共同支撑了深层 Transformer 的可训练性。

## 1. 为什么这些基础模块重要

Transformer 不只是 Attention。一个 block 里通常还有：

```text
Norm -> Attention -> Residual
Norm -> FFN -> Residual
```

如果没有归一化和残差，模型很深时训练会变得不稳定；如果没有激活函数，多层线性变换叠起来仍然接近线性表达，能力会很弱。

## 2. 残差连接

残差连接的形式是：

```text
输出 = 输入 + 子层计算结果
```

直觉：

- 子层不必从零学完整表示，只需要学习“在原输入上补什么”。
- 梯度可以沿着加法路径更顺畅地传回前面层。
- 深层网络更容易训练。

在 Transformer 里：

```text
x = x + Attention(Norm(x))
x = x + FFN(Norm(x))
```

## 3. LayerNorm

LayerNorm 会对单个样本内部的 hidden dimension 做归一化。

它适合 NLP 和 LLM，因为文本序列长度和 batch 情况经常变化，不能像图像任务那样强依赖 batch 统计。

直觉：

```text
把每个 token 的 hidden state 调整到更稳定的尺度
```

## 4. RMSNorm

RMSNorm 是 LayerNorm 的简化版本，很多现代 LLM 使用 RMSNorm。

它主要使用均方根来做尺度归一化，通常更省计算，效果也很稳定。

很多 Llama 系模型使用：

```text
RMSNorm + RoPE + SwiGLU + GQA
```

这几项组合经常出现在现代 Decoder-only LLM 中。

## 5. BatchNorm 为什么不常用于 LLM

BatchNorm 依赖 batch 维度统计，在 LLM 中有几个问题：

- 序列长度变化大。
- 自回归生成时 batch 统计不稳定。
- 分布式训练下同步统计有额外成本。
- 小 batch 或动态 batch 场景效果不稳。

所以 LLM 更常用 LayerNorm 或 RMSNorm。

## 6. Pre-Norm 与 Post-Norm

Post-Norm：

```text
x = Norm(x + Sublayer(x))
```

Pre-Norm：

```text
x = x + Sublayer(Norm(x))
```

现代 LLM 多偏向 Pre-Norm，因为深层训练更稳定，梯度更容易传递。

但 Post-Norm 在某些设置下也有优势，实际模型会结合规模和训练策略选择。

## 7. 激活函数

如果没有激活函数，多层线性层叠加仍然是线性变换，表达能力有限。

常见激活函数：

- ReLU：简单高效。
- GELU：BERT、GPT 等模型常用过。
- SiLU / Swish：平滑非线性。
- SwiGLU：现代 LLM 常见 FFN 变体。

## 8. SwiGLU 为什么常见

标准 FFN 可以理解为：

```text
x -> 升维 -> 激活 -> 降维
```

SwiGLU 引入门控机制，让模型可以控制哪些特征通过。

直觉：

```text
一条分支产生内容，一条分支决定哪些内容该放大或抑制。
```

它通常比普通 ReLU/GELU FFN 表达能力更强，因此在 Llama、Qwen 等现代模型里很常见。

## 9. 常见误区

### 误区一：Attention 是 Transformer 的全部

不是。Attention 负责 token 间信息交互，FFN 负责每个 token 内部的非线性加工，Norm 和 Residual 保证深层训练稳定。

### 误区二：归一化只是加速训练

归一化不仅影响速度，还影响训练稳定性、梯度传播和深层模型能否训起来。

### 误区三：RMSNorm 一定全面优于 LayerNorm

RMSNorm 常用于现代 LLM，但是否更好仍取决于架构、规模、训练设置和评估目标。

## 面试追问

### Q1：为什么 Transformer 常用 LayerNorm 而不是 BatchNorm？

因为 NLP 序列长度和 batch 情况变化大，自回归生成也不适合依赖 batch 统计；LayerNorm 对单个样本的 hidden dimension 归一化，更稳定。

### Q2：残差连接解决什么问题？

它让信息和梯度能更顺畅地跨层传播，使深层网络更容易训练，同时让子层学习增量变化。

### Q3：SwiGLU 相比普通 FFN 有什么优势？

SwiGLU 引入门控机制，能更灵活地控制特征流动，提升 FFN 表达能力，是现代 LLM 常见设计。

- LayerNorm / RMSNorm / BatchNorm 的差异。
- FFN 和激活函数为什么同样重要。
