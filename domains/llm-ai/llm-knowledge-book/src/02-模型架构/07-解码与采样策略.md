# 解码与采样策略

## 一句话结论

解码策略决定模型如何从“下一个 token 概率分布”变成最终文本。它不改变模型参数，但会显著影响回答的稳定性、创造性和重复程度。

## 1. 从 logits 到 token

模型每一步都会输出词表上每个 token 的分数，叫 logits。

```text
hidden state -> lm_head -> logits -> softmax -> probability
```

解码策略要做的事是：根据这个概率分布选择下一个 token。

## 2. Greedy Search

Greedy 每一步都选概率最高的 token。

优点：

- 稳定。
- 快。
- 可复现。

缺点：

- 容易保守。
- 可能陷入重复。
- 不适合开放式创作。

适合：

- 分类式回答。
- 结构化抽取。
- 稳定问答。

## 3. Beam Search

Beam Search 会保留多个候选序列，最后选整体概率较高的一条。

它在机器翻译等任务里常见，但在现代聊天 LLM 中不一定总适合。

原因是：最高概率序列不一定最自然、最有帮助，也可能更模板化。

## 4. Temperature

temperature 控制分布的平滑程度。

```text
temperature 低：更确定，更保守
temperature 高：更多样，更随机
```

常见直觉：

| temperature | 效果 |
| --- | --- |
| 0 或接近 0 | 更稳定，接近 greedy |
| 0.7 | 平衡稳定和多样性 |
| 1.0 以上 | 更发散，更有创意，也更容易出错 |

## 5. Top-k

Top-k 只在概率最高的 k 个 token 中采样。

例如 `top_k = 50`：

```text
只允许从前 50 个候选 token 中选
```

它能避免模型从极低概率 token 中乱选。

## 6. Top-p

Top-p 也叫 nucleus sampling。它不是固定候选数量，而是选择累计概率达到 p 的最小 token 集合。

例如 `top_p = 0.9`：

```text
从累计概率前 90% 的候选 token 中采样
```

Top-p 会根据分布形状动态调整候选集合大小。

## 7. Repetition Penalty

重复惩罚用于降低已经出现过的 token 再次出现的概率。

它可以缓解：

- 重复句子。
- 循环输出。
- 口水化回答。

但惩罚过强也会让文本变得不自然。

## 8. 解码策略怎么选

| 场景 | 推荐倾向 |
| --- | --- |
| 信息抽取 | 低 temperature，少随机 |
| 代码生成 | 中低 temperature，重视稳定 |
| 创意写作 | 较高 temperature，配合 top-p |
| 面试问答 | 中低 temperature，保证准确 |
| 数据生成 | 适当提高多样性，但要强评估 |

## 9. 解码和幻觉的关系

高 temperature 会增加多样性，也可能增加幻觉风险。

但幻觉不只是采样导致的。它还可能来自：

- 模型参数知识不足。
- prompt 约束不清。
- RAG 检索错误。
- 上下文证据缺失。
- 评估和校验不足。

所以不能只靠调低 temperature 解决幻觉。

## 10. 常见误区

### 误区一：temperature 越低越准确

不一定。低 temperature 更稳定，但如果模型本身第一选择就是错的，它会稳定地错。

### 误区二：top-k 和 top-p 是一回事

不是。top-k 固定候选数量，top-p 固定累计概率阈值。

### 误区三：解码策略能弥补模型能力不足

解码只能影响输出选择方式，不能让模型真正学会参数里没有的能力。

## 面试追问

### Q1：temperature 的作用是什么？

它调整 token 概率分布的尖锐程度。低 temperature 更确定，高 temperature 更多样但风险更高。

### Q2：top-k 和 top-p 有什么区别？

top-k 保留固定数量的高概率 token；top-p 保留累计概率达到阈值的一组 token，候选数量会动态变化。

### Q3：为什么聊天模型不总用 beam search？

因为最高概率序列不一定最有帮助，beam search 可能导致回答保守、模板化，在开放式聊天中不一定体验最好。

## 学习检查

学完本章后，应该能独立讲清：

- 模型输出 logits 后如何变成文本。
- greedy、beam、temperature、top-k、top-p 的差异。
- 为什么解码策略影响风格，但不能替代模型能力和评估。
