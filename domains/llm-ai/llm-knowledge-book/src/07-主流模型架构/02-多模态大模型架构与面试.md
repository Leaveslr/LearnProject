## 一、多模态模型基础

### 1.1 什么是多模态大语言模型 (MLLM)?

```
定义: 以大语言模型为"大脑"，结合视觉模型作为"眼睛"的统一系统

核心能力:
- 图像理解 (看图说话、视觉问答)
- 视频理解 (时序分析、动作识别)
- 音频理解 (语音识别、声音事件检测)
- 跨模态推理 (图表分析、文档理解)
```

### 1.2 MLLM 发展脉络

```
2023年初: LLaMA + CLIP 简单拼接
    ↓
2023年中: GPT-4V 发布，多模态能力突破
    ↓
2023年底: LLaVA 1.0/1.5 开源生态
    ↓
2024年: MiniGPT-4, CogVLM, Qwen-VL, Gemini
    ↓
2025年: GPT-4o, Gemini 2.0, 多模态 Agent 爆发
```

### 1.3 多模态 vs 单模态核心差异

| 维度 | 单模态 LLM | 多模态 MLLM |
|------|------------|-------------|
| **输入** | 文本 | 文本 + 图像/视频/音频 |
| **模态对齐** | 无 | 视觉-语言对齐 |
| **视觉编码器** | 无 | CLIP/ViT/EVA |
| **训练复杂度** | 较低 | 高 (多模态数据) |
| **幻觉问题** | 文本幻觉 | 视觉幻觉更严重 |

## 二、视觉编码器技术

### 2.1 主流视觉编码器对比

| 编码器 | 参数量 | 视觉能力 | 计算效率 | 代表模型 |
|--------|--------|----------|----------|----------|
| **CLIP ViT** | 86M-428M | 中等 | 高 | LLaVA |
| **EVA-CLIP** | 4B | 强 | 中 | LLaVA 1.6 |
| **SigLIP** | 400M | 强 | 中 | Gemini |
| **DINOv2** | 300M-1B | 强 (自监督) | 中 | 学术研究 |
| **Qwen-VL Encoder** | - | 强 | - | Qwen-VL |
| **InternViT** | 6B | 很强 | 中 | InternVL |

### 2.2 CLIP 视觉编码器原理

```python
# CLIP 视觉编码器核心
class CLIPVisionEncoder:
    def __init__(self):
        self.vit = ViT(
            image_size=224,
            patch_size=16,
            hidden_size=768,
            num_layers=12
        )
    
    def encode(self, images):
        # 图像分块 + 位置编码
        patches = self.image_to_patches(images)  # [B, N, 768]
        
        # Transformer 编码
        features = self.vit(patches)  # [B, N+1, 768]
        
        # [CLS] token 作为图像表示
        return features[:, 0]
```

### 2.3 ViT (Vision Transformer) vs CNN

```
ViT 优势:
- 长距离依赖建模能力强
- 与 LLM 架构统一 (都是 Transformer)
- 可利用预训练大模型迁移

CNN 优势:
- 局部特征提取能力强
- 计算效率高
- 对小目标更敏感

融合趋势: ViT + CNN 混合架构
```

### 2.4 动态分辨率 vs 固定分辨率

| 方案 | 实现 | 优势 | 劣势 |
|------|------|------|------|
| **固定分辨率** | 统一 resize 到 224x224 | 简单 | 丢失细节 |
| **动态分辨率** | 分块处理不同大小 | 保留细节 | 计算复杂 |
| **_anyres** | 多分辨率混合 | 平衡 | 训练复杂 |

```python
# LLaVA-1.6 ANYRES 策略
def anyres_image_process(image, base_size=224, grid_pinpoints):
    # 原始图像 resize 到基础大小
    base_image = resize(image, base_size)
    
    # 将图像分割成 grid
    patches = split_into_grid(image, grid)
    
    # 独立编码每个 patch
    patch_features = [encoder(p) for p in patches]
    
    # 全局 + 局部特征拼接
    return concat([global_feature] + patch_features)
```

## 三、模态对齐方法

### 3.1 投影层设计

```
问题: 视觉特征空间 ≠ 语言特征空间
解决: 投影层 (Projector) 将视觉特征映射到语言空间

常见投影方式:
- 线性层 (Linear)
- MLP 两层 (MLP)
- 交叉注意力 (Cross Attention)
- Q-Former (BLIP-2)
```

### 3.2 投影层对比

| 投影方式 | 参数量 | 对齐能力 | 计算开销 | 代表模型 |
|----------|--------|----------|----------|----------|
| **线性** | ~10M | 中等 | 低 | LLaVA 1.0 |
| **MLP** | ~50M | 强 | 中 | LLaVA 1.5 |
| **Q-Former** | ~200M | 很强 | 高 | BLIP-2, InstructBLIP |
| **Cross Attn** | ~100M | 很强 | 高 | CogVLM |

```python
# 线性投影
vision_features = encoder(images)  # [B, N, 1024]
projected = W_proj @ vision_features  # [B, N, 4096]
llm_input = concat([text_tokens, projected], dim=1)

# MLP 投影 (LLaVA 1.5)
class MLPProjector(nn.Module):
    def __init__(self, vision_dim, llm_dim):
        self.layers = nn.Sequential(
            nn.Linear(vision_dim, llm_dim),
            nn.GELU(),
            nn.Linear(llm_dim, llm_dim)
        )
```

### 3.3 Q-Former 原理 (BLIP-2)

```
核心思想: 使用 Cross Attention 交互学习 Query 和视觉特征

结构:
- Query tokens (32个可学习向量)
- Cross Attention 与视觉特征交互
- 输出固定长度 (768维) 的表示

优势: 强对齐能力 + 压缩视觉信息
```

### 3.4 模态对齐训练阶段

```
阶段1: 表征学习
- 冻结 LLM 和视觉编码器
- 仅训练投影层
- 目标: 学会"翻译"视觉→语言

阶段2: 指令微调
- 冻结视觉编码器
- 训练投影层 + 部分 LLM
- 目标: 学习多模态指令遵循

阶段3 (可选): 全参数微调
- 解冻所有参数
- 小学习率
- 目标: 极致性能
```

## 四、主流多模态模型架构

### 4.1 GPT-4V 架构 (闭源推测)

```
推测架构:
- 视觉编码器: 定制 ViT (可能类似 CLIP)
- 语言模型: GPT-4 (未公开)
- 对齐方式: 专有技术

核心能力:
- 图像理解: 强
- 文本处理: 极强 (继承 GPT-4)
- 复杂推理: 极强
```

### 4.2 LLaVA 系列演进

| 版本 | 时间 | 视觉编码器 | 投影 | 关键改进 |
|------|------|-----------|------|----------|
| LLaVA 1.0 | 2023.4 | CLIP ViT-L | 线性 | 开创开源 MLLM |
| LLaVA 1.5 | 2023.11 | CLIP ViT-L | MLP | 增加学术问答数据 |
| LLaVA 1.6 | 2024.1 | EVA-CLIP ViT-G | MLP | ANYRES 分辨率提升 |
| LLaVA 2.0 | 2024.7 | SigLIP | MLP | 更大训练数据 |
| LLaVA-OneVision | 2024.8 | SigLIP-SO400M | MLP | 统一图像/视频/文档 |

```python
# LLaVA 架构简化
class LLaVA(nn.Module):
    def __init__(self, config):
        self.vision_encoder = CLIPVisionEncoder(config.vision)
        self.projector = MLPProjector(
            config.vision_dim, 
            config.llm_dim
        )
        self.llm = LLaMA(config.llm)
    
    def forward(self, images, texts):
        # 视觉编码
        vis_features = self.vision_encoder(images)
        
        # 投影到语言空间
        vis_embeddings = self.projector(vis_features)
        
        # 拼接输入 LLM
        inputs = self.llm.prepare_inputs(
            text_embeddings=text_embeddings,
            vis_embeddings=vis_embeddings
        )
        
        return self.llm(inputs)
```

## 五、多模态训练策略

### 5.1 训练数据构成

```
多模态训练数据:

1. 图文对 (Image-Text Pairs)
   - 互联网爬取的描述性文本
   - Alt-text, 标题, 描述
   - 质量较低, 数量巨大

2. 指令数据 (Instruction Data)
   - VQA (视觉问答)
   - 图像描述
   - 视觉对话
   - 高质量, 需要人工标注

3. 学术数据 (Academic Data)
   - ScienceQA
   - TextVQA
   - GQA
   - 专业化, 高质量
```

### 5.2 训练策略对比

| 策略 | 训练参数 | 数据需求 | 效果 | 成本 |
|------|----------|----------|------|------|
| **Frozen** | 投影层 | 中等 | 中等 | 低 |
| **Linear Probe** | 投影层 | 中等 | 较好 | 低 |
| **Full FT** | 全部 | 大量 | 最好 | 高 |
| **LoRA** | LoRA adapter | 中等 | 较好 | 中 |
| **BLIP-2 两阶段** | Q-Former + adapter | 大量 | 好 | 高 |

## 六、面试高频问题

### Q1: 多模态大模型和单模态的核心区别是什么？

**参考答案**:

核心区别在于**模态融合**：

1. **输入处理**: 多模态需要额外处理视觉/音频编码
2. **特征对齐**: 视觉特征空间 → 语言特征空间的映射
3. **训练数据**: 需要高质量多模态配对数据 (稀缺)
4. **幻觉问题**: 多模态幻觉 (看图说错话) 比文本幻觉更严重

```python
# 单模态 LLM
def forward(text):
    return llm(text)

# 多模态 MLLM
def forward(images, text):
    vis_features = vision_encoder(images)
    vis_embeddings = projector(vis_features)
    return llm(text_embeddings, vis_embeddings)
```

### Q2: 视觉编码器为什么选择 ViT 而不是 CNN？

**参考答案**:

| 维度 | ViT 优势 | CNN 优势 |
|------|----------|----------|
| **架构统一** | 与 LLM 都是 Transformer | 需要额外适配 |
| **远程依赖** | 全局注意力 | 局部感受野 |
| **预训练** | CLIP 大规模对齐 | ImageNet 分类 |
| **计算** | 序列长度 = 图像块数 | 特征图层级 |

**选择建议**:
- 通用图像理解: **ViT (CLIP/EVA)**
- 细粒度视觉任务: **CNN + ViT 混合**
- 实时场景: **EfficientNet/MobileNet**

### Q3: 投影层为什么重要？有哪些实现方式？

**参考答案**:

投影层是**模态桥梁**，关键作用：
1. 维度变换: 视觉特征维度 → LLM 输入维度
2. 语义对齐: 让视觉特征能被 LLM "理解"
3. 信息压缩: 减少 token 数量，控制计算量

| 实现 | 参数量 | 对齐质量 | 计算开销 |
|------|--------|----------|----------|
| 线性 | ~10M | 一般 | 低 |
| MLP | ~50M | 好 | 中 |
| Q-Former | ~200M | 很好 | 高 |
| Cross Attn | ~100M | 很好 | 高 |

**趋势**: 学术界探索更强对齐，工业界倾向轻量投影

### Q4: 多模态幻觉问题如何解决？

**参考答案**:

多模态幻觉类型:
1. **对象幻觉**: 图中没有的目标说"有"
2. **属性幻觉**: 颜色/数量等属性错误
3. **关系幻觉**: 空间/动作关系描述错误

解决策略:

```
1. 数据层面
   - 高质量图文对齐数据
   - 负样本数据 (图有但描述错的)

2. 训练层面
   - BLIP-2 的 ITC + ITC 训练
   - LLaVA 的精确指令微调
   - 对齐损失增强

3. 推理层面
   - 置信度检测
   - Self-Correction (让模型自检)
   - Chain-of-Verification

4. 后处理
   - 视觉 grounding 工具
   - 目标检测验证
```

### Q5: 如何选择多模态模型用于生产？

**参考答案**:

选择维度:

| 维度 | 选项 | 权衡 |
|------|------|------|
| **能力** | GPT-4V > 开源 | 成本/隐私 |
| **开源** | InternVL > LLaVA > Qwen-VL | 调优能力 |
| **中文** | Qwen-VL > LLaVA (需微调) | 中文 OCR |
| **文档** | 专用文档模型 > 通用 | 泛化能力 |
| **部署** | 小模型 (7B) > 大模型 | 延迟/成本 |

**实际推荐**:

```
简单图像理解 → LLaVA-1.6 (7B, 开源免费)
复杂文档 OCR → GPT-4V / Claude 3
中文为主 → Qwen-VL2
企业自托管 → InternVL2-26B
```
