# Quant Finance

这是金融量化领域的长期知识体系。

它覆盖从金融市场基础、概率统计、数据工程、策略研究、回测、风控、交易执行到项目实践的完整链路。

## 目录

```text
00-roadmap/          # 学习路线、问题清单、术语表
01-foundations/      # 市场结构、资产类别、收益风险基础
02-math-stats/       # 概率统计、时间序列、因子模型
03-data-engineering/ # 行情、财务、另类数据、清洗与特征
04-strategies/       # 趋势、均值回归、因子、多资产、套利
05-backtesting/      # 回测框架、滑点、手续费、过拟合
06-risk-portfolio/   # 风控、组合、仓位、回撤
07-execution/        # 订单、执行、实盘系统
08-research-log/     # 策略研究记录
09-projects/         # 可运行项目和实验
10-content-angles/   # 可转成笔记、视频、课程的选题
```
