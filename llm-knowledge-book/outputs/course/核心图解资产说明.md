# 核心图解资产说明

> 目标：为后续制作 PPT、图文和视频画面提供图解蓝图。这里先定义每张图应该表达什么，后续可转成 Mermaid、PPT 或视觉稿。

## 图 1：LLM 全链路图

主题：

```text
文本 -> token -> embedding -> transformer -> logits -> decoding -> output
```

必须展示：

- tokenizer。
- embedding。
- position。
- transformer blocks。
- lm head。
- sampling。

讲解重点：

- LLM 不是直接读文字，而是读 token。
- 模型每一步输出的是下一个 token 的概率分布。

## 图 2：Transformer Block 结构图

主题：

```text
Norm -> Attention -> Residual -> Norm -> FFN -> Residual
```

必须展示：

- self-attention。
- FFN。
- residual connection。
- LayerNorm / RMSNorm。

讲解重点：

- Attention 负责 token 间交互。
- FFN 负责每个 token 自身特征加工。
- Norm 和 Residual 保证深层训练稳定。

## 图 3：QKV 最小例子图

主题：

```text
Q 问：我想找谁？
K 答：我有什么特征？
V 提供：我能贡献什么信息？
```

必须展示：

- 一个 4-token 短句。
- 当前 token 的 Q。
- 其他 token 的 K。
- attention weights。
- 加权 V。

讲解重点：

- QK 用来算权重。
- V 才是被聚合的信息。

## 图 4：MHA / MQA / GQA / MLA 对比图

主题：

不同注意力变体的 KV heads 数量不同，导致 KV Cache 成本不同。

必须展示：

- MHA：每个 Q head 都有 K/V。
- MQA：所有 Q heads 共享一组 K/V。
- GQA：一组 Q heads 共享一组 K/V。
- MLA：压缩潜表示。

讲解重点：

- GQA/MQA 主要优化推理成本。
- KV heads 越少，KV Cache 越省。

## 图 5：KV Cache 显存公式图

主题：

```text
batch × seq_len × layers × 2 × kv_heads × head_dim × bytes
```

必须展示：

- K 和 V 两份。
- seq_len 增长导致 cache 增长。
- batch size 增长导致 cache 增长。
- GQA 减少 kv_heads。

讲解重点：

- KV Cache 是用显存换速度。
- 长上下文和高并发会迅速吃显存。

## 图 6：RAG 排障流程图

主题：

```text
query -> retrieval -> rerank -> context -> generation -> citation
```

必须展示：

- 每一层可能出错。
- 每一层对应评估指标。
- 错误归因路径。

讲解重点：

- RAG 答错不能直接怪模型。
- 先看证据有没有召回，再看生成是否忠实。

## 图 7：Agent Trace 图

主题：

```text
goal -> plan -> tool call -> observation -> next action -> final
```

必须展示：

- 状态。
- 工具调用参数。
- 工具返回。
- 错误恢复。
- HITL 节点。

讲解重点：

- Agent 评估必须看过程。
- 工具调用风险要可追踪、可中断、可恢复。

## 图 8：训练链路图

主题：

```text
pretraining -> SFT -> preference alignment -> PEFT / domain adaptation
```

必须展示：

- 预训练学能力。
- SFT 学指令。
- RLHF / DPO 学偏好。
- LoRA 做低成本适配。

讲解重点：

- 不同训练阶段解决的问题不同。
- 数据形态也不同。

## 图 9：项目表达结构图

主题：

```text
背景 -> 问题 -> 方案 -> 指标 -> 失败案例 -> 复盘
```

必须展示：

- baseline。
- 改进指标。
- failure case。
- trade-off。

讲解重点：

- 面试不是堆技术名词，而是证明你做过取舍和复盘。
