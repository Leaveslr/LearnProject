# 阶段练习与测评题库

> 目标：用练习题判断是否真正掌握，而不是只读过章节。

## 使用方式

每个阶段分三类题：

- 概念题：检查是否理解定义和直觉。
- 计算 / 推导题：检查是否能落到公式、流程或指标。
- 工程题：检查是否能用于真实系统和面试表达。

评分建议：

| 得分 | 判断 |
| --- | --- |
| 90-100 | 能独立讲解并迁移 |
| 75-89 | 基本掌握，但需要补边界和案例 |
| 60-74 | 知道概念，但不能稳定回答追问 |
| <60 | 需要回到主线章节重学 |

## 阶段一：基础原理与 Tokenizer

### 概念题

1. 用一句话解释交叉熵。
2. 交叉熵和最大似然是什么关系？
3. 为什么 token id 本身不能表达语义？
4. token embedding 和上下文表示有什么区别？
5. 为什么 Tokenizer 会影响推理成本？
6. BPE 为什么能处理未登录词？
7. temperature、top-k、top-p 分别控制什么？

### 计算 / 推导题

1. 如果模型给正确 token 的概率是 0.8、0.1、0.01，分别比较 `-log P` 的惩罚大小。
2. 给一组简单词频：`low, lower, lowest, new, newer`，演示一次 BPE 合并。
3. 给定同一句中文和英文 prompt，估计为什么 token 数可能不同。

### 工程题

1. RAG 系统里为什么 chunk 太长会影响 embedding 检索？
2. 为什么低 temperature 不一定能消除幻觉？
3. 如果一个模型中文回答成本偏高，你会从 tokenizer 角度检查什么？

### 通过标准

能独立讲清：

```text
文本 -> token -> embedding -> 语言模型目标 -> 解码输出
```

## 阶段二：Transformer 与现代架构

### 概念题

1. Q、K、V 分别是什么？
2. 为什么 Attention 要除以 `sqrt(d_k)`？

6. RoPE 为什么能表达位置信息？
7. MHA、MQA、GQA、MLA 的核心差异是什么？
8. MoE 为什么参数量大但计算量不同比例增加？

### 计算 / 推导题

1. 给定序列长度 `n=4096`，说明 Attention 计算量为什么和 `n^2` 相关。
2. 画出一个 token 从 embedding 到 logits 的 Transformer block 路径。
3. 比较 MHA 32 个 KV heads 和 GQA 8 个 KV heads 的 KV Cache 比例。

### 工程题

1. 为什么现代 LLM 常用 GQA 而不是完整 MHA？

```text
Embedding + Position -> Attention -> FFN -> Norm/Residual -> logits
```

## 阶段三：训练、微调与对齐

### 概念题

1. 预训练、SFT、RLHF、DPO 分别解决什么问题？

3. 对比 ZeRO-1、ZeRO-2、ZeRO-3 分别节省哪些训练状态。

### 工程题

1. 什么时候应该用微调，什么时候应该用 RAG？
2. 微调后模型出现通用能力下降，你会怎么排查？

### 通过标准

## 阶段四：推理优化与部署

### 概念题

1. prefill 和 decode 有什么区别？
2. KV Cache 存的是什么？
3. KV Cache 省了什么，又消耗了什么？

6. TTFT 和 TPOT 有什么区别？
7. GPTQ、AWQ、GGUF 分别适合什么场景？

### 计算 / 推导题

1. 用公式估算 KV Cache 显存：

```text
batch_size × seq_len × num_layers × 2 × num_kv_heads × head_dim × bytes_per_element
```

假设：

```text
batch_size = 4
seq_len = 8192
num_layers = 32
num_kv_heads = 8
head_dim = 128
bytes_per_element = 2
```

估算显存。

2. 如果 GQA 把 KV heads 从 32 降到 8，KV Cache 理论上降为多少？
3. 压测时为什么要同时看 P50、P95、P99？

### 工程题

1. 一个系统 TTFT 高，你会怎么排查？
2. 一个系统 TPOT 高，你会怎么优化？
3. 为什么吞吐提高可能导致单请求延迟变差？
4. 量化后如何评估是否能上线？

### 通过标准

能做出：

- KV Cache 显存计算。
- 推理压测指标表。
- 部署优化方案。

### 题目 1：完整链路解释

用 10 分钟讲清：

```text
用户输入一句话后，LLM 如何从 token 开始，一步步生成回答？
```

必须包含：

- tokenizer。
- embedding。
- attention。
- FFN / norm / residual。
- logits。
- decoding。
- KV Cache。

设计一个企业制度问答系统。

必须包含：

- 文档解析。
- chunk 策略。
- 检索和 rerank。
- prompt 组织。
- 引用溯源。
- golden set。
- 错误排查。
