# 面试卡：LoRA

## 高频问法

- LoRA 为什么参数高效？
- LoRA 的低秩假设是什么？
- QLoRA 和 LoRA 有什么区别？

## 30 秒回答

LoRA 冻结基础模型权重，只训练两个低秩矩阵 A 和 B，用 `Delta W = B*A` 近似完整权重更新。因为 rank `r` 远小于原矩阵维度，可训练参数从 `d*k` 降到 `r*(d+k)`，显著减少显存和保存成本。

## 2 分钟回答

全参数微调会更新完整权重 `W0`，即 `W_new = W0 + Delta W`。LoRA 假设下游任务的参数更新具有低内在秩，所以把 `Delta W` 分解成两个小矩阵 `B*A`。训练时冻结 `W0`，只更新 A/B；前向时输出等于原始输出加上 LoRA 增量。B 常零初始化，这样训练开始时 LoRA 分支为 0，不破坏原模型行为。QLoRA 则是在量化基础模型上训练 LoRA adapter，进一步降低显存。

## 追问

### Q1：为什么 B 零初始化？

回答：让初始 `B*A=0`，模型一开始等价于原模型，再逐渐学习任务增量。

### Q2：r 越大越好吗？

回答：不一定。r 大表达更强，但参数和过拟合风险也增加。

### Q3：LoRA 适合什么场景？

回答：适合领域适配、风格适配、指令微调等，不一定适合大规模知识重写。

## 容易翻车

- 错误：LoRA 是训练一个小模型。
- 正确：LoRA 是在大模型层上训练低秩增量。
