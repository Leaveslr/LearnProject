# 知识卡：LoRA

## 资料来源

- 主笔记：[LoRA 原理与实战](../../src/03-训练技术/07-LoRA详解.md)

## 一句话结论

LoRA 的本质是在冻结原模型权重的基础上，用两个小的低秩矩阵学习权重增量，从而用很少参数完成微调。

## 它解决什么问题

- 全参数微调显存高、训练慢、保存成本大。
- 下游任务往往不需要更新全部高维参数。
- LoRA 用低秩更新近似完整参数更新。

## 核心直觉

- 原模型像一本已经写好的大书。
- 全参微调是改整本书。
- LoRA 是贴一小叠补丁页，只记录这次任务需要改的方向。

## 最小例子

```text
全量更新：Delta W 是 d*k 大矩阵
LoRA：Delta W = B*A
A: r*k
B: d*r
r 远小于 d 和 k
```

如果 `d=k=4096, r=8`，LoRA 参数远小于完整矩阵。

## 关键机制

1. 冻结基础权重 `W0`。
2. 增加可训练矩阵 `A` 和 `B`。
3. 前向时使用 `W0 + alpha/r * B*A`。
4. 推理时可以合并权重，也可以加载 adapter。

## 工程应用

- 指令微调、领域适配、角色风格适配。
- 多任务保存多个 adapter，切换成本低。
- QLoRA 结合 4-bit 量化进一步降显存。

## 常见误区

- LoRA 是重新训练小模型。
- r 越大一定越好。
- LoRA 没有质量损失。

## 边界和反例

- 大规模知识注入或深度能力改变，LoRA 未必足够。
- 数据质量差时，省参数也救不了效果。
- target modules 选错会导致训练收益弱。
