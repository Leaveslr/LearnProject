# 知识讲解生产体系 v3：真人讲解感评估

## 本轮新增维度

新增正式评估维度：`真人讲解感`。

这个维度用于判断内容是否像真人老师在讲，而不是像机器把资料重新排版。

通过标准同步更新为：

- 总分不低于 85/100。
- 准确性、边界/反例、可讲解性、真人讲解感都不低于 4 分。
- 真人讲解感低于 4 分时，即使内容准确，也必须重写。

## 新权重

新增 `真人讲解感` 权重 10。为保持总分 100，压缩了偏后处理的两个维度权重：

- 可讲解性：10 -> 5
- 内容转化：5 -> 3
- 迁移练习：5 -> 2
- 真人讲解感：新增 10

## 观察

最像真人讲解的是 RAG 评估和 Agent 工具调用，因为它们从真实排障和工程误区进入，句子天然更像人在提醒。

相对更容易产生机器味的是 Attention、GQA、LoRA 这类公式/缩写密集知识点。后续做发布级版本时，要优先补：

- 更自然的口播转场。
- 更少的缩写堆叠。
- 更多“你可能会误会”的提醒。
- 更多具体对象或手边例子。

## v4 执行动作

已对真人讲解感为 4 分的知识点继续迭代：

- KV Cache：补口播开场、自然转场、Q 为什么不缓存的卡点提醒。
- Tokenizer：补“模型看到世界的入口”开场、安检类比和成本提醒。
- Attention：补“先把公式放一边”的开场、公式前转场和长上下文成本提醒。
- MHA / MQA / GQA / MLA：补“别先背名字”的开场和盯住 KV 头的讲法。
- LoRA：补“有必要改完整本书吗”的开场和“只学变化”的转场。

这些改动已写入对应 `teaching-algorithm-methods/validation-cases/*-walkthrough.md`。

迭代后真人讲解感均达到 5/5。
