## 本轮沉淀的去机器味规则

### 1. 先把公式放一边

公式密集主题容易产生机器味。开场先用一句生活化问题接住学习者，再回到公式。

示例：

```text
我们先别急着背 KV Cache 的定义。
```

### 2. 每个抽象概念要有讲解动作

不是只写“Q 表示查询”，而是说：

```text
当前 token 仍然会提问，历史 token 仍然会回答。
```

### 3. 主动预判误会

真人老师会提前说“这里很多人会误会”。这比最后列误区更自然。

### 4. 用一句工程人话收束

结尾不要机械复述定义，要把它压成能在面试或课堂里讲出来的一句话。

示例：

```text
它省掉历史 K/V 的重复计算，但把压力转移到了显存和缓存管理上。
```
