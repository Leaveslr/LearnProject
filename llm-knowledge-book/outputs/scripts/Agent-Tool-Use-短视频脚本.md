# 短视频脚本：Agent 不是会调工具就完了

## 选题

本期讲：Agent 工具调用的行动循环。

## 开头 0-5 秒

```text
Function calling 不等于 Agent，真正难的是可控地循环调用工具。
```

## 第一段 5-25 秒

```text
Agent 工具调用不是一次 API 请求，而是理解任务、选择工具、填写参数、执行、观察结果，再决定下一步。
```

画面：task -> tool -> observation -> next step。

## 第二段 25-70 秒

```text
好工具要有清楚名称、明确边界、强类型参数、稳定返回结构和可处理错误码。
工具描述越模糊，模型越容易误调用。
```

## 第三段 70-100 秒

```text
工程上还要保存 trace，记录每一步工具选择、参数、结果和成本。
高风险操作必须加权限和人工确认。
```

## 结尾

```text
一句话记住：Agent 不是多了工具，而是多了受约束的行动循环。
```
