# 短视频脚本：GQA 为什么能省 KV Cache？

## 选题

本期讲：MHA、MQA、GQA、MLA 的推理成本差异。

## 开头 0-5 秒

```text
GQA 省显存，不是因为少了 Q 头，而是因为少了 KV 头。
```

## 第一段 5-25 秒

```text
MHA 里，每个 Query 头都有独立 K/V。推理时历史 K/V 要进 KV Cache，头越多，缓存越大。
```

画面：32 Q -> 32 KV。

## 第二段 25-70 秒

```text
MQA 最激进，所有 Q 头共享一组 K/V。
GQA 折中，把 Q 头分组，比如 32 个 Q 头、8 个 KV 头，每 4 个 Q 头共享一组 KV。
这样比 MHA 省，又比 MQA 更保留表达能力。
```

画面：MHA/MQA/GQA 对比表。

## 第三段 70-100 秒

```text
MLA 更进一步，缓存低维 latent，需要时再恢复 K/V。
所以它不是简单减少几个头，而是压缩 KV 表示。
```

## 结尾

```text
一句话记住：这些变体都在做同一件事，在表达能力和 KV Cache 成本之间取舍。
```
