# 短视频脚本：LoRA 为什么只训练两个小矩阵？

## 选题

本期讲：LoRA 的低秩增量直觉。

## 开头 0-5 秒

```text
LoRA 不是训练一个小模型，而是在大模型上加一组低秩补丁。
```

## 第一段 5-25 秒

```text
全参微调是更新完整权重：W_new = W0 + Delta W。
问题是 Delta W 和原权重一样大，训练和保存都很贵。
```

## 第二段 25-70 秒

```text
LoRA 把 Delta W 分解成 B 乘 A。
A 和 B 都很小，因为中间 rank r 远小于原矩阵维度。
训练时冻结 W0，只训练 A/B。
```

画面：Delta W = B * A。

## 第三段 70-100 秒

```text
这样可训练参数从 d*k 降到 r*(d+k)。
QLoRA 则是在量化基础模型上再训练 LoRA，进一步省显存。
```

## 结尾

```text
一句话记住：LoRA 学的不是完整新权重，而是低秩权重增量。
```
