## 讲解目标

这条视频不用多个例子发散，只用 `我今天很 -> 开心` 贯穿到底，让用户理解：

- logits 是候选答案的原始分数
- softmax 把分数归一成概率
- 交叉熵只盯正确 token 的概率
- `P(正确 token)` 越高，loss 越低
- 反向传播会推动正确 logit 上升、错误概率下降
- loss mask 决定哪些 token 真正参与训练
- PPL 低不等于任务一定成功

## 脚本结构验证

这条视频采用新的知识视频脚本结构：

```text
少量概念建立地图 -> 一个例子贯穿机制 -> 判断题证明用户真的懂了
```

在这条视频里：

- 概念地图：交叉熵到底在扣什么分
- 贯穿例子：`我今天很 -> 开心`
- 机制拆解：logits、softmax、概率、loss、反向传播
- 关键细节：`P=0.90/0.30/0.01` 的 loss 数字直觉
- 判断题：概率升高 loss 会怎么变、mask 错会怎样、PPL 为什么会误导
