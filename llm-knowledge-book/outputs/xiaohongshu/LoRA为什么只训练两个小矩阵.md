## 推荐标题

LoRA 为什么只训练两个小矩阵？

## 封面文案

LoRA 不是小模型

## 正文

LoRA 经常被说成“参数高效微调”，但这句话太抽象。

一句话结论：

> LoRA 冻结原模型，只训练两个低秩矩阵来表示权重增量。

### 1. 全参微调怎么做？

全参微调会更新完整权重：

```text
W_new = W0 + Delta W
```

问题是 `Delta W` 和原矩阵一样大。

### 2. LoRA 怎么做？

LoRA 假设这个更新可以低秩近似：

```text
Delta W = B * A
```

如果 rank `r` 很小，可训练参数就从 `d*k` 变成 `r*(d+k)`。

### 3. 为什么有效？

预训练模型已经有大量通用能力。

下游任务通常只需要在某些方向上微调，不一定要更新所有参数。

### 4. 常见误区

误区：LoRA 是训练一个小模型。  
正确：LoRA 是给大模型加低秩增量。

误区：r 越大越好。  
正确：r 大表达更强，但参数和过拟合风险也更高。

## 面试回答卡

```text
LoRA 冻结基础权重 W0，
只训练两个低秩矩阵 A 和 B，
用 B*A 近似完整权重更新 Delta W。
这样可训练参数从 d*k 降到 r*(d+k)，
显著降低显存和保存成本。
```
