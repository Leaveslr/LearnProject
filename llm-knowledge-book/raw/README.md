# Raw Materials

这个目录用于保存原始资料和外部项目快照，不建议作为第一学习入口。

## 使用方式

- 优先阅读 `../src` 中整理后的学习笔记。
- 当正文需要补充细节、出处或案例时，再回到本目录查原始材料。
- 从 `raw` 提炼内容到 `src` 时，需要做结构化整理，避免直接复制成问答堆叠。
- 图片、notebook、zip、脚本等文件只作为资料留存；除非已经被正文引用，否则不纳入主线学习目录。

## 当前资料分区

- `FAQ_Of_LLM_Interview/`：大模型算法岗面试题和相关代码、图片、notebook。
- `llms-interview-questions/`：LLM 面试题集合。
- `ai-engineering-interview-questions/`：AI Engineering 面试题集合。

## 整理规则

1. 一个知识点先进入 `src` 的主线章节，再进入真实面试题索引。
2. 同一主题不要在多个章节重复展开；重复内容应合并为“基础说明 + 进阶专题 + 面试追问”。
3. 面试题需要补充标准回答、追问方向和常见误区。
4. 工程类内容需要补充适用场景、性能指标、成本权衡和失败案例。
