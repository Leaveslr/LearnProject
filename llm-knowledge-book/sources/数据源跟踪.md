# 数据源跟踪

> 用于记录后续补充知识时优先跟踪的课程、论文、官方文档、GitHub 仓库和博客。

## 使用规则

- 官方文档、课程、论文优先级高于二手博客。
- 每次新增章节时，在“关联主题”里标注来源。
- 面试题仓库用于收集高频问题，不直接作为事实依据。
- 对更新快的内容，如 Agent 框架、推理框架、模型架构，需要定期复查。
