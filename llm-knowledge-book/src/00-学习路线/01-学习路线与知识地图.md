# 学习路线与知识地图

这份路线用于把零散知识点串成可执行的学习计划。每一阶段都建议形成自己的笔记产出，而不是只读材料。

## 总体目标

完成本知识库后，应能达到三个标准：

1. 能从原理解释 LLM 的核心模块，而不是只背概念。
2. 能把训练、推理、RAG、Agent 放到真实工程链路中讨论取舍。
3. 能围绕项目经历回答面试追问，包括为什么这么做、哪里会失败、如何评估效果。

## 阶段零：基础原理与 Tokenizer

学习目标：

- 理解机器学习、深度学习和语言模型的最小基础。
- 理解交叉熵、Embedding、归一化、优化器为什么会反复出现在 LLM 中。
- 理解 tokenizer、subword、next token prediction 和 perplexity。

建议阅读：

- [机器学习与深度学习基础](../01-基础原理/01-机器学习与深度学习基础.md)
- [Tokenizer 与语言模型基础](../02-模型架构/00-Tokenizer与语言模型基础.md)

验收问题：

- 交叉熵和最大似然是什么关系？
- Embedding 为什么可以表示语义相似性？
- BPE 为什么适合开放词表问题？
- next token prediction 为什么能支撑复杂语言能力？

## 阶段一：模型架构基础

学习目标：

- 理解 Transformer 的整体结构和自回归生成逻辑。
- 掌握 Attention 的 Q/K/V、Mask、Softmax、复杂度。
- 理解 RoPE、ALiBi、位置外推等位置编码方案。
- 理解 MHA、MQA、GQA、MLA 的显存和效果权衡。
- 理解 MoE 的路由、专家负载均衡和推理成本。

建议阅读：

- [Transformer 架构详解](../02-模型架构/01-Transformer详解.md)
- [注意力机制深度剖析](../02-模型架构/02-注意力机制.md)
- [位置编码](../02-模型架构/03-位置编码.md)
- [多头注意力变体](../02-模型架构/04-多头注意力变体.md)
- [MoE 详解](../02-模型架构/06-MoE详解.md)

验收问题：

- 为什么 Attention 的复杂度是 O(n^2)？
- 为什么现在大模型常用 GQA/MQA，而不是完整 MHA？
- RoPE 为什么能表达相对位置信息？
- MoE 为什么能扩大参数量但不同比例增加推理 FLOPs？

## 阶段二：训练与对齐

学习目标：

- 理解预训练数据、目标函数、优化器和训练稳定性。
- 区分预训练、SFT、RLHF、DPO、GRPO 的目标和数据形态。
- 理解 LoRA、QLoRA、Prefix Tuning 等 PEFT 方法的适用边界。
- 能解释对齐训练的收益、成本和能力退化风险。

建议阅读：

- [预训练](../03-训练技术/01-预训练.md)
- [SFT 与指令微调](../03-训练技术/02-SFT与指令微调.md)
- [RLHF 与对齐技术](../03-训练技术/03-RLHF对齐.md)
- [PEFT 高效微调](../03-训练技术/06-PEFT高效微调.md)
- [LoRA 原理与实战](../03-训练技术/07-LoRA详解.md)
- [强化学习对齐深度解析](../03-训练技术/08-强化学习对齐深度解析.md)

验收问题：

- SFT、RLHF、DPO 分别需要什么数据？
- DPO 为什么可以绕过显式 Reward Model？
- LoRA 的低秩假设是什么，rank 怎么选？
- GRPO 相比 PPO 省掉了什么，代价是什么？

## 阶段三：推理优化与部署

学习目标：

- 理解 KV Cache 的显存占用和长上下文成本。
- 理解 PagedAttention、Continuous Batching、Prefix Cache 的工程意义。
- 掌握 FP16、BF16、INT8、INT4、NF4 的区别。
- 能从延迟、吞吐、显存、精度角度选择部署方案。

建议阅读：

- [KV Cache 与推理优化](../04-推理优化/02-KV-Cache优化.md)
- [FlashAttention 与 PagedAttention](../04-推理优化/03-FlashAttention与PagedAttention.md)
- [数值精度、量化与部署基础](../04-推理优化/03-模型量化与部署/01-数值精度与量化基础.md)
- [部署与推理加速面试题](../09-真实面试题/部署-推理加速.md)

验收问题：

- KV Cache 的显存和 batch size、层数、hidden size、序列长度是什么关系？
- PagedAttention 解决的核心问题是什么？
- AWQ、GPTQ、GGUF 分别适合什么部署场景？
- 为什么量化评估不能只看 perplexity？

## 阶段四：RAG 与应用系统

学习目标：

- 理解 RAG 的索引、检索、重排、生成链路。
- 能设计分块策略、混合检索、rerank 和引用溯源。
- 掌握 RAG 评估：召回、准确性、忠实性、答案相关性。
- 能区分 RAG、微调、Agent 在业务场景中的边界。

建议阅读：

- [RAG 系统架构](../05-应用技术/01-RAG系统架构.md)
- [RAG 与 Agent 系统深度解析](../05-应用技术/02-RAG与Agent系统深度解析.md)
- [RAG 优化面试题](../09-真实面试题/rag优化.md)

验收问题：

- chunk size 和 overlap 应该怎么定？
- 稀疏检索、向量检索、混合检索各自解决什么问题？
- rerank 放在哪一层，为什么？
- 如何定位 RAG 回答错误是检索问题还是生成问题？

## 阶段五：Agent 与多模态

学习目标：

- 理解 Agent 的规划、工具调用、记忆、反思和评估。
- 掌握 ReAct、Plan-and-Execute、多 Agent 协作的差异。
- 理解多模态大模型的视觉编码器、投影层和模态对齐。
- 能讨论 Agent 的可靠性、安全边界和生产落地风险。

建议阅读：

- [Agent 进阶](../06-Agent/02-Agent进阶：多模态Agent与生产实战.md)

- [多模态大模型架构与面试](../07-主流模型架构/02-多模态大模型架构与面试.md)

验收问题：

- ReAct 和普通 function calling 有什么区别？
- Agent 记忆系统为什么不能简单等同于长上下文？
- 多 Agent 系统什么时候比单 Agent 更好？
- VLM 的视觉 token 如何接入 LLM？

## 后续维护建议

- 新增笔记时先放进对应阶段，再考虑是否需要进入 README。
- 每个知识点都补充至少一个“面试追问”和一个“工程坑”。
- 面试题按主题归档，公司题只作为来源，不作为主线结构。
- 每月回看一次补齐清单，优先补影响主线连续性的章节。
