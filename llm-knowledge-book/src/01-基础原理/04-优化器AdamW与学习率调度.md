# 优化器、AdamW 与学习率调度

## 一句话结论

优化器决定模型参数怎么根据梯度一步步更新。AdamW 是 LLM 训练中最常见的优化器之一，学习率调度则决定每一步迈多大。

## 1. 训练到底在更新什么

模型有大量参数。训练时，每个 batch 会经历：

```text
前向计算 -> 得到 loss -> 反向传播 -> 得到梯度 -> 优化器更新参数
```

梯度告诉我们：如果想让 loss 变小，参数应该往哪个方向改。

优化器决定：沿着这个方向怎么走、走多大、要不要考虑历史梯度。

## 2. SGD 的直觉

SGD 是最基础的更新方式：

```text
新参数 = 旧参数 - 学习率 x 梯度
```

直觉：

- 梯度是方向。
- 学习率是步长。
- loss landscape 是地形。

学习率太大，可能一步跨过最优点；学习率太小，训练会很慢。

## 3. Adam 为什么常用

Adam 会记录两类历史信息：

- 一阶动量：梯度的滑动平均，像是最近方向的惯性。
- 二阶动量：梯度平方的滑动平均，用来调整不同参数的步长。

直觉上，Adam 会给不同参数自适应地安排更新幅度。

这对大模型很重要，因为不同层、不同参数的梯度尺度可能差异很大。

## 4. AdamW 的关键：解耦权重衰减

AdamW 中的 `W` 来自 weight decay。

weight decay 的作用是防止参数无限变大，可以理解为给参数一个“别太夸张”的约束。

AdamW 的重点是：把权重衰减从梯度更新里解耦出来，让正则化行为更清晰、更稳定。

在大模型训练中，AdamW 常用于：

- 预训练。
- SFT。
- LoRA 微调。
- 偏好对齐训练。

## 5. 学习率为什么需要调度

训练不是从头到尾都适合同一个学习率。

常见策略：

- warmup：训练开始时从小学习率慢慢升上来。
- cosine decay：中后期逐渐降低学习率。
- linear decay：线性下降。
- constant：保持不变，常见于某些微调场景。

## 6. Warmup 的意义

刚开始训练时，模型参数还没稳定，梯度可能波动很大。如果一上来学习率太高，训练容易炸。

warmup 像是让模型先热身：

```text
小步走 -> 稳定后正常走 -> 后期慢慢收敛
```

## 7. LLM 训练里常见的相关概念

### Gradient Clipping

限制梯度最大范数，防止梯度爆炸。

### Gradient Accumulation

显存不够时，把多个小 batch 的梯度累积起来，再更新一次参数。它模拟更大的全局 batch size。

### Weight Decay

控制参数规模，提升泛化。

### Batch Size

batch size 会影响训练稳定性、吞吐和泛化。大 batch 不只是“更快”，还会改变优化动态。

## 8. 常见误区

### 误区一：学习率越大训练越快

只在一定范围内成立。太大会震荡、发散或训练不稳定。

### 误区二：AdamW 总是比 SGD 好

在 LLM 训练中 AdamW 很常见，但不是所有场景都绝对最优。选择优化器要看任务、规模、稳定性和资源。

### 误区三：微调只要改学习率就行

微调还要看数据质量、batch size、训练轮数、loss mask、LoRA rank、目标模块、评估集和过拟合风险。

## 面试追问

### Q1：Adam 和 SGD 的核心区别是什么？

SGD 主要按当前梯度更新；Adam 会结合历史一阶和二阶动量，为不同参数自适应调整更新幅度。

### Q2：AdamW 为什么适合大模型训练？

它自适应性强，对不同参数尺度更友好，并且通过解耦 weight decay 提供更稳定的正则化。

### Q3：为什么需要 warmup？

训练初期梯度不稳定，warmup 用较小学习率启动，降低训练发散风险。
