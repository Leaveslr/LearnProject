# 第二章：注意力机制深度剖析

## 2.1 注意力机制核心公式

### 2.1.1 Scaled Dot-Product Attention

注意力机制的核心是**缩放点积注意力**：

```
Attention(Q, K, V) = softmax(QK^T / √d_k)V
```

其中：
- Q (Query)：查询向量——"我想要什么信息"
- K (Key)：键向量——"我包含什么信息"
- V (Value)：值向量——"信息的实际内容"
- d_k：键向量的维度（用于缩放）

### 2.1.2 为什么需要缩放？

当 d_k 较大时，点积的数值会很大，导致 softmax 进入饱和区域（梯度接近 0）。

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    Scaled Dot-Product Attention
    Q, K, V: [batch, heads, seq_len, head_dim]
    """
    d_k = Q.size(-1)
    
    # 核心计算：QK^T
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    
    # 可选：应用掩码
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    
    # Softmax 得到注意力权重
    attention_weights = F.softmax(scores, dim=-1)
    
    # 加权求和
    output = torch.matmul(attention_weights, V)
    
    return output, attention_weights
```

## 2.2 注意力机制的工作原理

### 2.2.1 直观理解

```
输入序列: "The cat sat on the mat"

当我们处理 "cat" 时：
┌────────────────────────────────────────────────────┐
│ Query ("cat"): 我想知道关于 cat 的什么信息？          │
│                                                     │
│ 与所有 Key 计算相似度：                              │
│   "The"    → 0.1                                  │
│   "cat"    → 0.8  ← 最相关！                       │
│   "sat"    → 0.4                                  │
│   "on"     → 0.2                                  │
│   "the"    → 0.1                                  │
│   "mat"    → 0.2                                  │
│                                                     │
│ 使用这些权重对 Value 加权求和                         │
│ 得到关于 "cat" 的上下文感知表示                       │
└────────────────────────────────────────────────────┘
```

### 2.2.2 自注意力的意义

1. **全局感受野**：每个位置都能直接 attend 到序列中的任意其他位置
2. **动态权重**：根据内容动态计算注意力权重
3. **并行计算**：所有位置的注意力可以同时计算

## 2.3 Multi-Head Attention (MHA)

### 2.3.1 为什么要用多头？

不同的注意力头可以学习关注不同的语义关系：

```
输入句子: "The animal didn't cross the street because it was too tired"

多头注意力可以捕获：
┌────────────────────────────────────────────────────────┐
│ Head 1 (语法关系)                                     │
│   "animal" ←→ "was" (主谓关系)                        │
│   "it" ←→ "animal" (指代关系) ✓                       │
├────────────────────────────────────────────────────────┤
│ Head 2 (语义角色)                                     │
│   "animal" 是"tired"的施事                            │
│   捕获实体-属性关系                                    │
├────────────────────────────────────────────────────────┤
│ Head 3 (位置关系)                                     │
│   关注句法结构中的相对位置                              │
└────────────────────────────────────────────────────────┘
```

### 2.3.2 MHA 代码实现

```python
import torch
import torch.nn as nn
import math

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        assert d_model % num_heads == 0
        
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        self.d_model = d_model
        
        # 线性变换
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)
        self.W_O = nn.Linear(d_model, d_model)
    
    def split_heads(self, x, batch_size):
        """将维度分割成多个头"""
        x = x.view(batch_size, -1, self.num_heads, self.head_dim)
        return x.permute(0, 2, 1, 3)  # [batch, heads, seq_len, head_dim]
    
    def forward(self, Q, K, V, mask=None):
        batch_size = Q.size(0)
        
        # 线性变换 + 分头
        Q = self.split_heads(self.W_Q(Q), batch_size)
        K = self.split_heads(self.W_K(K), batch_size)
        V = self.split_heads(self.W_V(V), batch_size)
        
        # Scaled Dot-Product Attention
        d_k = Q.size(-1)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        
        attention_weights = F.softmax(scores, dim=-1)
        attention_output = torch.matmul(attention_weights, V)
        
        # 合并多头
        attention_output = attention_output.permute(0, 2, 1, 3).contiguous()
        attention_output = attention_output.view(batch_size, -1, self.d_model)
        
        # 最终线性变换
        output = self.W_O(attention_output)
        
        return output, attention_weights
```

## 2.4 注意力机制的变体

### 2.4.1 Multi-Query Attention (MQA)

**动机**：减少 KV Cache 显存占用

```
MHA: 每个 Query 头有独立的 K 和 V
     Head 1: Q1 ──→ K1, V1
     Head 2: Q2 ──→ K2, V2
     (8 个头 = 8 组 K, V)

MQA: 所有 Query 头共享一组 K 和 V
     Head 1: Q1 ─┐
     Head 2: Q2 ─┼──→ K_shared, V_shared
     (8 个头 = 1 组 K, V)
```

**优点**：大幅减少 KV Cache
**缺点**：可能损失部分表达能力

### 2.4.2 Grouped-Query Attention (GQA)

**动机**：在 MHA 和 MQA 之间取得平衡

```
GQA: Query 头分成 G 组，每组共享 K 和 V

Group 1:
  Head 1: Q1 ─┐
  Head 2: Q2 ─┴──→ K_g1, V_g1

Group 2:
  Head 3: Q3 ─┐
  Head 4: Q4 ─┴──→ K_g2, V_g2
```

**例子**：Llama 3 使用 8 个 KV 头，32 个 Query 头

### 2.4.3 Multi-Head Latent Attention (MLA)

**动机**：DeepSeek-V2 提出的低秩压缩方案

**核心思想**：将 KV 信息压缩到低维潜在向量 c_t

```
                    ┌──> 动态解压(W_UK) ──> 多头 K
输入 X ──> 压缩 ───┤
          (W_DKV)   └──> 动态解压(W_UV) ──> 多头 V
                       ▲
                       │
          [只有 c_t 被缓存，体积极小！]
```

**优势**：显存占用大幅减少，同时保持表达能力

## 2.5 注意力机制的复杂度分析

### 2.5.1 时间复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| **标准 Self-Attention** | O(n²·d) | n=序列长度, d=维度 |
| **MQA/GQA** | O(n²·d + n·d·g) | g=KV头数 |
| **线性注意力** | O(n·d²) | 近似方法 |

### 2.5.2 空间复杂度

主要是注意力矩阵的存储：

```
标准 Attention: O(n²)  # 存储 n×n 的注意力矩阵

Flash Attention: O(n)  # 通过重计算优化显存
```

## 2.6 Flash Attention

### 2.6.1 核心思想

将注意力计算重新组织，使中间结果始终保存在高速缓存（SRAM）中，减少 HBM 读写。

```
标准 Attention:
  HBM ──→ 读取完整 Q,K,V ──→ 计算 ──→ 存储 n×n 矩阵 ──→ 读写瓶颈

Flash Attention:
  SRAM ──→ 分块读取 Q,K,V ──→ 增量计算 ──→ 不存储完整矩阵
           (高速)                    (流式)
```

### 2.6.2 使用示例

```python
# PyTorch 2.0+ 内置 Flash Attention
import torch.nn.functional as F

output = F.scaled_dot_product_attention(
    Q, K, V,
    attn_mask=None,      # Flash Attention 自动处理
    dropout_p=0.0,
    is_causal=True,      # 因果掩码
    scaling=None
)
```

## 2.7 面试高频问题

### Q1: 为什么要 scale（除以 √d）？

> 当 d_k 较大时，点积的值会很大，导致 softmax 梯度接近 0（梯度消失）。除以 √d_k 可以使点积的方差保持稳定。

### Q2: Q、K、V 分别代表什么？

> Q 是查询向量，表示"我需要什么信息"；K 是键向量，表示"我有什么信息"；V 是值向量，表示"信息的实际内容"。Q 和 K 计算相似度，匹配结果用于加权 V。

### Q3: 多头注意力比单头好在哪里？

> 不同的头可以学习关注不同的语义子空间（如语法、指代、语义关系），提高模型的表达能力。同时可以并行计算，利用硬件。

### Q4: 如何理解自注意力？

> 自注意力中，Q、K、V 都来自同一个输入序列。每个位置都可以 attend 到序列中的所有其他位置，从而捕获长距离依赖关系。

### Q5: Transformer 中的注意力有哪些？

> 主要有三种：Encoder Self-Attention（双向）、Decoder Self-Attention（因果）、Cross-Attention（Decoder 关注 Encoder 输出）。

## 2.8 代码实战：实现完整 Transformer Attention

```python
import torch
import torch.nn as nn
import math
import torch.nn.functional as F

class SelfAttention(nn.Module):
    """自注意力机制"""
    def __init__(self, embed_size, heads):
        super().__init__()
        self.embed_size = embed_size
        self.heads = heads
        self.head_dim = embed_size // heads
        
        assert self.head_dim * heads == embed_size, "embed_size must be divisible by heads"
        
        # Q, K, V 变换
        self.values = nn.Linear(embed_size, embed_size)
        self.keys = nn.Linear(embed_size, embed_size)
        self.queries = nn.Linear(embed_size, embed_size)
        self.fc_out = nn.Linear(embed_size, embed_size)
    
    def forward(self, values, keys, query, mask=None):
        N = query.shape[0]
        value_len, key_len, query_len = values.shape[1], keys.shape[1], query.shape[1]
        
        # 变换 + 分头
        values = self.values(values)
        keys = self.keys(keys)
        queries = self.queries(query)
        
        values = values.reshape(N, value_len, self.heads, self.head_dim)
        keys = keys.reshape(N, key_len, self.heads, self.head_dim)
        queries = queries.reshape(N, query_len, self.heads, self.head_dim)
        
        # 缩放点积注意力
        energy = torch.einsum("nqhd,nkhd->nhqk", [queries, keys]) / math.sqrt(self.head_dim)
        
        if mask is not None:
            energy = energy.masked_fill(mask == 0, float("-1e20"))
        
        attention = F.softmax(energy, dim=3)
        
        # 加权求和
        out = torch.einsum("nhql,nlhd->nqhd", [attention, values]).reshape(N, query_len, self.heads * self.head_dim)
        
        return self.fc_out(out)
```
