# 多头注意力机制变体详解

## MHA vs MQA vs GQA vs MLA

### 1. Multi-Head Attention (MHA)

**标准的多头注意力**，每个头有独立的 Q、K、V：

```
┌────────────────────────────────────────────────────────────┐
│                      MHA (Multi-Head Attention)               │
├────────────────────────────────────────────────────────────┤
│                                                              │
│  Q 头 1 ──→ K1, V1 ──┐                                    │
│  Q 头 2 ──→ K2, V2 ──┼──→ Attention ──→ Concat ──→ Output│
│  Q 头 3 ──→ K3, V3 ──┤                                    │
│  Q 头 4 ──→ K4, V4 ──┘                                    │
│                                                              │
│  如果 8 个头: 8 组独立的 K, V                                │
│                                                              │
└────────────────────────────────────────────────────────────┘
```

### 2. Multi-Query Attention (MQA)

**所有 Query 头共享一组 K 和 V**，大幅减少 KV Cache：

```
┌────────────────────────────────────────────────────────────┐
│                      MQA (Multi-Query Attention)            │
├────────────────────────────────────────────────────────────┤
│                                                              │
│  Q 头 1 ─┐                                                  │
│  Q 头 2 ─┼──→ K_shared, V_shared ──→ Attention ──→ Output│
│  Q 头 3 ─┤                                                  │
│  Q 头 4 ─┘                                                  │
│                                                              │
│  所有 Q 共享一组 K, V → KV Cache 大幅减少                     │
│                                                              │
└────────────────────────────────────────────────────────────┘
```

### 3. Grouped-Query Attention (GQA)

**在 MHA 和 MQA 之间取得平衡**，Query 头分成 G 组：

```
┌────────────────────────────────────────────────────────────┐
│                      GQA (Grouped-Query Attention)          │
├────────────────────────────────────────────────────────────┤
│                                                              │
│  Group 1:                                                   │
│    Q 头 1 ─┐                                                 │
│    Q 头 2 ─┼──→ K_g1, V_g1 ──┐                             │
│  Group 2:   │                        │                       │
│    Q 头 3 ─┼──→ K_g2, V_g2 ──┼──→ Attention ──→ Output   │
│  Group 3:   │                        │                       │
│    Q 头 4 ─┘                        │                       │
│                                                              │
│  例如: 32 个 Q 头, 8 个 KV 头 → 每 4 个 Q 头共享一组 KV      │
│                                                              │
└────────────────────────────────────────────────────────────┘
```

### 4. Multi-Head Latent Attention (MLA)

**DeepSeek-V2 提出的低秩压缩方案**：

```
┌────────────────────────────────────────────────────────────┐
│                      MLA (Multi-Head Latent Attention)       │
├────────────────────────────────────────────────────────────┤
│                                                              │
│                    ┌──> 动态解压(W_UK) ──> 多头 K          │
│  输入 X ──> 压缩 ──┤                                        │
│              (W_DKV) └──> 动态解压(W_UV) ──> 多头 V         │
│                         ▲                                   │
│                         │                                   │
│              [只缓存低维潜在向量 c_t, 体积极小!]            │
│                                                              │
└────────────────────────────────────────────────────────────┘
```

## 对比总结

| 类型 | Q 头 | K/V 头 | KV Cache | 表达能力 | 代表模型 |
|------|------|--------|----------|---------|---------|
| **MHA** | H | H | 大 | 最强 | BERT、T5 |
| **MQA** | H | 1 | 最小 | 较弱 | PaLM |
| **GQA** | H | G (G < H) | 中等 | 平衡 | LLaMA 3 |
| **MLA** | H | 压缩 | 极小 | 强 | DeepSeek-V2 |

## 代码示例

```python
class Attention(nn.Module):
    def __init__(self, d_model, num_q_heads, num_kv_heads):
        super().__init__()
        self.num_q_heads = num_q_heads
        self.num_kv_heads = num_kv_heads
        self.head_dim = d_model // num_q_heads
        
        # Q: num_q_heads 个头
        self.wq = nn.Linear(d_model, num_q_heads * self.head_dim)
        
        # K, V: num_kv_heads 个头 (可能少于 Q)
        self.wk = nn.Linear(d_model, num_kv_heads * self.head_dim)
        self.wv = nn.Linear(d_model, num_kv_heads * self.head_dim)
        
        # 输出投影
        self.wo = nn.Linear(num_q_heads * self.head_dim, d_model)
    
    def forward(self, x):
        bsz, seq_len, _ = x.shape
        
        # Q, K, V 投影
        q = self.wq(x).view(bsz, seq_len, self.num_q_heads, self.head_dim)
        k = self.wk(x).view(bsz, seq_len, self.num_kv_heads, self.head_dim)
        v = self.wv(x).view(bsz, seq_len, self.num_kv_heads, self.head_dim)
        
        # GQA: 扩展 K, V 到 Q 的头数
        if self.num_kv_heads < self.num_q_heads:
            # 将 KV 头扩展到 Q 头数
            num_kv_groups = self.num_q_heads // self.num_kv_heads
            k = k.repeat_interleave(num_kv_groups, dim=2)
            v = v.repeat_interleave(num_kv_groups, dim=2)
        
        # 计算注意力
        # ... 后续计算
```

## 面试要点

1. **MHA**：表达能力最强，但 KV Cache 最大
2. **MQA**：KV Cache 最小，但可能损失表达能力
3. **GQA**：LLaMA 3 采用，平衡方案
4. **MLA**：DeepSeek-V2 采用，低秩压缩
