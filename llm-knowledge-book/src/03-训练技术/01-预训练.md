# 第四章：预训练与自监督学习

## 4.1 预训练概述

预训练（Pretraining）是训练大语言模型的第一阶段，目标是让模型从海量无标注数据中学习通用的语言表示和世界知识。

### 4.1.1 预训练的特点

| 特点 | 说明 |
|------|------|
| **数据规模** | 通常是数万亿（Trillions）级别的 token |
| **计算资源** | 需要数百到数千块 GPU，耗时数周到数月 |
| **目标** | 学习通用能力，而非特定任务 |
| **损失函数** | 通常是语言建模损失 |

---

## 4.2 语言建模目标

### 4.2.1 自回归语言建模（Autoregressive LM）

给定前文，预测下一个 token：

```
P(x_1, x_2, ..., x_n) = ∏ P(x_t | x_1, ..., x_{t-1})
```

**目标函数**：

```
L_CLM = -Σ log P(x_t | x_1, ..., x_{t-1})
```

GPT 系列、LLaMA 等模型采用这种目标。

### 4.2.2 掩码语言建模（Masked LM）

随机掩码部分 token，预测被掩码的部分：

```
输入: "The [MASK] sat on the mat"
目标: 预测 [MASK] = "cat"
```

BERT 采用这种目标。

### 4.2.3 对比学习（Contrastive Learning）

学习让相似样本在表示空间中靠近，不相似样本远离：

```
L = -log exp(sim(x, x⁺)) / Σ exp(sim(x, x⁻))
```

## 4.3 预训练数据

### 4.3.1 数据来源

| 来源 | 比例 | 内容 |
|------|------|------|
| **网页** | 60-70% | Common Crawl、WebText、OpenWebText |
| **书籍** | 10-20% | BooksCorpus、GPT-2 的 WebText |
| **代码** | 5-15% | GitHub、StackOverflow |
| **学术** | 2-5% | ArXiv、PubMed |
| **对话** | 1-5% | Reddit、社交媒体 |

### 4.3.2 数据处理流程

```
原始数据
    │
    ▼
[质量过滤] ──→ 去除低质量、重复、有毒内容
    │
    ▼
[去重] ────→ 文档级、段落级、句子级去重
    │
    ▼
[格式转换] ─→ 统一编码、标准化
    │
    ▼
[Tokenizer] ─→ BPE/SentencePiece 分词
    │
    ▼
训练数据
```

## 4.4 分词器（Tokenizer）

### 4.4.1 BPE（Byte Pair Encoding）

一种基于频率的子词分词算法：

```python
# BPE 训练过程
1. 从字符级开始
2. 统计最高频的相邻 token 对
3. 合并为新的 token
4. 重复直到达到目标词表大小

# 示例
"low" → "l o w"
"lower" → "l o w e r"
"lowest" → "l o w e s t"

训练后: lo w er ▁low ▁lower ▁lowest
```

### 4.4.2 SentencePiece

Google 开发的通用分词器，支持：
- BPE 或 Unigram 语言模型
- 无需预分词
- 支持多语言

### 4.4.3 分词器选择

| 模型 | 分词器 | 词表大小 |
|------|--------|---------|
| GPT-2 | BPE | 50,257 |
| GPT-4 | Tiktoken | ~100,000 |
| LLaMA | SentencePiece | 32,000 |
| Qwen | BPE | 151,936 |

## 4.5 Scaling Laws

### 4.5.1 Chinchilla Scaling Laws

DeepMind 提出的 scaling laws 指出：

```
最优模型大小 ∝ 数据量的平方根
```

给定计算预算 C，最优的参数量 N 和数据量 D：

```
N_opt ∝ C^0.5
D_opt ∝ C^0.5
```

### 4.5.2 计算公式

```
C ≈ 6 * N * D
```

其中：
- C: 计算量（FLOPs）
- N: 参数量
- D: 数据 token 数

## 4.6 预训练代码示例

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from datasets import load_dataset

# 加载模型和分词器
model_name = "meta-llama/Llama-3-8B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# 准备数据
def tokenize_function(examples):
    result = tokenizer(
        examples["text"],
        truncation=True,
        max_length=2048,
        padding="max_length"
    )
    result["labels"] = result["input_ids"].copy()
    return result

dataset = load_dataset("your_dataset")
tokenized_dataset = dataset.map(tokenize_function, batched=True)

# 训练配置
training_args = TrainingArguments(
    output_dir="./output",
    per_device_train_batch_size=4,
    gradient_accumulation_steps=8,
    learning_rate=1e-5,
    num_train_epochs=1,
    bf16=True,  # 使用 BF16 加速
    logging_steps=10,
    save_steps=1000,
)

# 训练
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset,
)
trainer.train()
```

## 4.7 预训练关键技术

### 4.7.1 混合精度训练

```python
# BF16 训练（推荐用于 A100/H100）
model = model.to(dtype=torch.bfloat16)
training_args.bf16 = True

# FP8 训练（2026 年新趋势）
training_args.fp16 = False
training_args.fp8 = True  # 需要 H100/B200
```

### 4.7.2 梯度累积

当显存不足时，通过累积多个 batch 的梯度来模拟大批量训练：

```python
# 逻辑批大小 = 物理批大小 × 累积步数
effective_batch_size = per_device_batch_size * gradient_accumulation_steps
```

### 4.7.3 分布式训练

```
┌─────────────────────────────────────────────┐
│           分布式训练策略                       │
├─────────────────────────────────────────────┤
│  数据并行 (Data Parallel)                    │
│    - 每个 GPU 有完整模型                     │
│    - 不同数据分片                            │
│    - 同步梯度                               │
├─────────────────────────────────────────────┤
│  张量并行 (Tensor Parallel)                  │
│    - 模型参数按维度分割                       │
│    - 需要高速互联（NVLink）                  │
│    - TP=8 表示 8 GPU 分割一层               │
├─────────────────────────────────────────────┤
│  流水线并行 (Pipeline Parallel)              │
│    - 不同 GPU 计算不同层                      │
│    - 需要微批次减少空闲                      │
├─────────────────────────────────────────────┤
│  ZeRO 优化 (Zero Redundancy Optimizer)      │
│    - ZeRO-1: 优化器状态分片                   │
│    - ZeRO-2: + 梯度分片                      │
│    - ZeRO-3: + 参数分片                      │
└─────────────────────────────────────────────┘
```

## 4.8 预训练中的常见问题

### Q1: 如何选择预训练数据配比？

> 需要根据目标应用场景调整。通用模型用均衡配比；代码模型增加代码数据；数学模型增加学术数据。

### Q2: 数据质量如何保证？

> 1. 使用高质量数据源（书籍、学术论文）
> 2. 规则过滤（去广告、去模板）
> 3. 基于分类器的质量过滤
> 4. 去重（MinHash、SimHash）

### Q3: 预训练需要多少数据？

> Chinchilla 定律建议：参数量 N 和 token 数 D 应该大约相等。例如 70B 参数模型需要约 7×10^10 tokens。
