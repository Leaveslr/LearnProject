# 算法与复杂知识讲解方法论研究

本目录用于沉淀一套面向编程初学者的算法与复杂技术知识讲解方法论。研究对象包括优秀算法课程、图文教程、公开视频字幕/文字稿，以及 Karpathy、李宏毅等复杂知识讲解名师的公开资料。

## 研究目标

- 梳理“一个知识点如何被拆解”的稳定方法。
- 提炼“从问题到直觉、从直觉到代码/数学”的讲解顺序。
- 总结视频讲解中有效的语言、节奏、重复、类比、转场技巧。
- 产出可复用的讲解脚本模板、检查清单和验证案例。

## 目录结构

- `raw-materials/`：原始资料索引、链接、摘录、字幕/文字稿片段和来源说明。
- `analysis-notes/`：对每位老师/每个样本的拆解笔记。
- `abstracted-methods/`：抽象出来的讲解框架、脚本模板、检查清单。
- `validation-cases/`：用具体知识点验证方法论是否可用。
- `outputs/`：最终手册、简版清单和可直接复用的成品。
- `outputs/conversation-usage-guide.md`：在对话框中加载和使用本方法论的提示词模板。

## 资料筛选标准

- 优先公开、稳定、可引用的官方页面、课程页、讲义、博客、视频字幕或文字稿。
- 优先能体现“初学者友好”的资料：有动机、有例子、有手算过程、有代码/伪代码、有复杂度或正确性说明。
- 视频样本优先选有字幕、文字稿、章节或完整讲义支撑的内容。
- 若无法稳定获取视频字幕，使用公开视频页、课程讲义、官方课件或第三方 transcript 页面替代，并在索引中注明。
