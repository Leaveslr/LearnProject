# 讲解检查清单

## 讲之前

- [ ] 我能用一句话说清楚这个知识解决什么问题。
- [ ] 我知道学习者需要哪些前置知识。
- [ ] 我准备了一个 5-8 步内能手算的小例子。
- [ ] 我准备了一个大规模例子说明它为什么有价值。
- [ ] 我知道最容易误解的前置条件和边界条件。

## 讲的时候

- [ ] 先讲朴素做法，再讲新方法。
- [ ] 先讲直觉，再讲术语。
- [ ] 先手算，再写代码。
- [ ] 每个变量都解释“代表什么”，不是只解释“是什么类型”。
- [ ] 每一步都说明“为什么可以这么排除/合并/转移”。
- [ ] 复杂度从关键动作推导，不直接背结论。
- [ ] 中途有阶段性总结，让学习者知道自己走到哪了。

## 讲完后

- [ ] 学习者能说出这个知识适用的前提。
- [ ] 学习者能手动走完一个小例子。
- [ ] 学习者能把伪代码翻译成代码。
- [ ] 学习者能解释至少一个常见错误。
- [ ] 学习者能完成一个同型练习和一个轻微变式。
