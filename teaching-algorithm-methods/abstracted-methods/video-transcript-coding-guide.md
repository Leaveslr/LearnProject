# 视频字幕讲解动作标注指南

## 标注目标

从视频字幕/文字稿中提取“老师实际怎么讲”，而不是只总结知识点。重点关注语言、节奏、转场、重复和铺垫。

## 标注字段

| 字段 | 含义 |
| --- | --- |
| source | 视频或文字稿来源链接 |
| timestamp | 时间戳或章节位置 |
| segment_summary | 这一段在讲什么 |
| teaching_action | 讲解动作，如开场钩子、类比、手算、总结 |
| learner_problem | 它解决了学习者什么困惑 |
| reusable_pattern | 可复用表达或结构 |
| caution | 可能误导或需要补充的地方 |

## 常见讲解动作标签

- `hook`：制造问题感。
- `analogy`：类比。
- `contrast`：对比笨办法和新办法。
- `manual_walkthrough`：手算或手推。
- `state_naming`：给变量/状态命名。
- `formalization`：从直觉过渡到公式/伪代码。
- `code_mapping`：说明代码和概念的对应关系。
- `repetition`：重复关键句。
- `checkpoint`：阶段性总结。
- `pitfall`：提醒误区。
- `transfer`：迁移到新问题。

## 分析问题

- 这段话是不是在降低进入门槛？
- 老师有没有先处理“为什么”，再处理“怎么做”？
- 类比是否说明了边界？
- 代码出现前，学习者是否已经知道变量代表什么？
- 数学出现前，学习者是否已经知道符号要表达什么关系？
- 结尾是否给了可迁移的判断标准？
