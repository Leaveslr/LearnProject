# 快速参考清单

## 一条主线

`问题 -> 直觉 -> 手算 -> 规则 -> 代码 -> 复杂度 -> 易错点 -> 练习`

## 三个不要

- 不要一上来背定义。
- 不要在没有手算前写代码。
- 不要只说 Big-O 结论，不解释关键动作。

## 五个必须

- 必须说明适用前提。
- 必须给小例子。
- 必须解释变量含义。
- 必须讲一个常见错误。
- 必须给迁移练习。

## 三个补救动作

- 听不懂公式：退回数字例子。
- 看不懂代码：退回手算表格。
- 不会迁移：补一个反例，明确适用边界。

## 视频讲解口头转场

- “我们先用最笨的办法试一次。”
- “现在你应该能感觉到它慢在哪里了。”
- “先别急着写代码，先看状态怎么变。”
- “这一步合法，是因为……”
- “把刚才的过程翻译成代码，就是下面几行。”
- “最后我们回头看，它为什么更快？”
