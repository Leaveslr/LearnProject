# 原始资料摘录与观察

## Khan Academy Binary Search

来源：https://www.khanacademy.org/computing/computer-science/algorithms/binary-search/a/binary-search

短摘录：

> Binary search is an efficient algorithm for finding an item from a sorted list of items.

观察：

- 开头先给“用途定义”：在有序列表中找元素。
- 紧接着给“核心动作”：不断把可能区域减半。
- 用猜数字游戏承接已有经验，再用星表搜索制造规模差异。
- 在讲代码前先强调算法描述必须比人类交流更完整：输入、输出、变量、循环条件都要明确。

可迁移技巧：

- 初学者第一次接触算法时，不要直接上代码；先让他知道“这个算法解决什么慢问题”。
- 用一个小到能手算的例子建立操作感，再用一个大规模例子解释为什么值得学。
- 讲实现前先补齐“电脑不会自动脑补”的事实，为变量和边界条件做认知铺垫。

## Karpathy Zero to Hero

来源：https://karpathy.ai/zero-to-hero.html

短摘录：

> building neural networks, from scratch, in code

观察：

- 课程承诺非常明确：不是先讲庞大理论，而是从代码里把神经网络“长出来”。
- 每个主题都是一个可运行项目：micrograd、makemore、GPT。
- 复杂度不是一次性抛给学习者，而是在代码版本迭代中逐层增加。

可迁移技巧：

- 对复杂概念，先构建最小可运行物，再解释抽象名词。
- 把“学习路径”设计成连续升级，而不是散点式概念堆叠。
- 每次引入新概念，都要回答：它解决了上一个版本的什么不足？

## 李宏毅 Machine Learning 2021

来源：https://speech.ee.ntu.edu.tw/~hylee/ml/2021-spring.php

观察：

- 课程页把视频、PPT、作业和补充资料放在同一张学习地图里。
- 官方课程说明明确照顾“完全没有机器学习基础”的学生，同时也覆盖前沿技术。
- 主题命名常带问题感，例如“NN 训练不起来咋办”，天然降低进入门槛。

可迁移技巧：

- 用学习者真正会问的问题命名小节，比纯学术名词更能降低心理门槛。
- 先给全貌地图，再拆局部模块，能减少初学者在复杂知识中的迷路感。
- 课件图示与口头解释配合时，要反复对齐“图里的箭头/方块到底对应现实中的什么”。
